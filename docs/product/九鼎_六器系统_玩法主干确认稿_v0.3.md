## 1. 核心体验与操作分工

战斗主导，摆包决定战斗方式。玩家通过空间分配影响祭坛争位，在保留构筑与点燃换取短时收益之间选择。

**战斗拾取 → 分配空间 → 第一名显灵／第二名作祟 → 择机点燃 → 重新构筑 → 局末选择传承。**

| 场合 | 已确认行为 |
| --- | --- |
| 战斗拾取 | 默认自动入仓；一次快捷操作可尝试改放祭坛，由系统寻找位置与朝向。祭坛放不下则尝试入仓，两处均放不下则留在地上。不替换、丢弃或移动旧物品。器魂优先并入已有同品质未满堆。 |
| 战斗操作 | 可一键点燃，不打开背包、不暂停；使用快捷栏指向的器。战斗中不能精细换装，不能靠打开背包进入无限时整理。 |
| 营地整理 | 精细挪位、比较、换装等留在营地；一炷香、技能冷却、增益及其他战斗计时一起暂停，离开后恢复。普通房间安全走动仍计时。 |
| 营地预览 | 实时显示票数与排名，但不触发排名变化带来的回血、伤害或掉落。离开时采用最终摆法，不补发试摆期间的战斗事件。 |

“每次拾取必须形成三秒决策”仍是待验证假设，不是固定交互时长。

## 2. 背包布局与空间成本

装装装装装装祭祭祭祭
装装装装装装祭祭祭祭
装装装装装装祭祭祭祭

| 区域 | 形状／格数 | 功能 |
| --- | --- | --- |
| 装备区 | 6×5，30 格 | 装备属性、身法、普通符效果及神兽所在区域。 |
| 祭坛 | 4×4，16 格 | 物品投票、契的持续规则效果、明确要求在祭坛生效的符效果。 |
| 仓库 | 最多 24 格 | 起步开放 4 格，腰带在本局内最多额外开放 20 格；不提供普通投票。 |

起步总计 50 格，满配 70 格；不做局外永久扩仓。起步容量及神兽最多影响祭坛左侧一列、共 4 格的局部加权是否足够有趣，均待白盒验证。

腰带换下、上坛、献祭或被毁导致缩仓时，关闭格位上的物品落到玩家脚边，不删除、不重排其他物品。营地先预览，战斗中发生则直接执行，空间恢复后可再拾取。初始四格的具体位置、扩仓开格顺序与负重映射留给实现规格细化。

## 4. 投票资格、票权与空间运算

普通投票来源为生肖道具、带主符的装备，以及有归属的传承残影。器魂无容器、不投票，上坛只占位，不提供强化效果；无符装备也不投票。

有投票资格与当前票数大于零是两回事：合格物品被对冲扣至零票，仍可接收分票；燃烧物、灰烬及被效果禁止投票的物品则没有当前投票资格。

| 物品 | 基础票数 |
| --- | --- |
| 生肖道具残／常／良／珍／异 | 1／1／2／3／4，每件只算一次，不按占格数重复。 |
| 传承残影 | 每件固定 1 票，不继承品质票权。 |
| 带主符装备 | 主符只决定唯一容器。原稿品质票权表作为候选参数，具体入池装备还需内容评审。 |

标准空间运算如下：

1. 基础票数乘所有适用倍率，最后统一向下取整一次。
2. 再扣相邻对冲票数，每件最低为零。
3. 若有生效的「镜中缘」，按合法配对分票一次，不重新触发倍率或对冲。

**神兽气息**取真实距离：2×2 神兽向外扩一格形成 4×4 范围，周围 12 格为实际气息。只加权同容器物品；触及物品任意一格，整件票数 ×2，覆盖更多格不重复翻倍。饕餮“不挑食”是喂食例外，气息不例外。「祠主」同样按触及中央 2×2 任一格即整件 ×1.5。

**相邻对冲**只认上下左右，斜角不算。每对对冲物品双方各减 1，接触多条边仍只算一次；接触多个对冲物品可累计扣票。例如基础 3 票，同时有 ×2、×1.5、×2，最后被一件对冲物品扣票，得到 17 票。

**镜中缘**要求两件合格物品绕祭坛中心旋转 180° 后占格恰好重合，每件最多配对一次。合并分配前的有效票后均分，奇数多出的 1 票给分配前较高者。例如 6 与 1 分成 4 与 3，总票仍为 7；不会把“8 格变成 16 格”。

**直接改票**作用于容器，不改变物品品质或基础票权；修正保留到本房间结束，挪位不能洗掉，离房清空。没有合格投票物品的容器不能仅靠额外票显灵。必须实际付出要求的票数才能获得对应收益，如「镜花」无可扣票时不得免费减伤。洗牌、强制第一等特殊改票与普通路径的完整优先级，随相应道具细化，不默认加入首轮样例。

## 5. 排名、显灵、作祟与封格

同一时刻只有一个显灵者和一个作祟者。

| 状态 | 裁决 |
| --- | --- |
| 最高票唯一 | 第一名显灵；有正票第二名时，由第二名作祟。 |
| 最高票并列 | 原第一名若仍在并列者中则保留；否则取并列者中最早入坛且仍留在祭坛上的物品归属。由显灵者的对冲容器作祟。 |
| 第一名唯一、第二名并列 | 原作祟者若仍在并列第二中则保留；否则取并列者中最早入坛且仍有资格的物品归属。 |
| 没有正票第二名 | 由显灵者的对冲容器补位作祟。 |
| 最终全零票 | 显灵与作祟均停止。 |

界面直接展示结果。相同状态包含当前显灵／作祟身份及物品入坛顺序，不能只保存票数而丢失平票裁决依据。

金·鼎作祟采用**封格**：祭坛左上角横向两格禁止放入新物品；已有物品正常投票、使用、移出和点燃。腾空后不能回填，作祟结束才开放。封格不扣票，不产生因失票而反复切换排名的循环。

「看门」采用**锁物**：受锁物品不能移动、使用、点燃；第一名所属物品中有锁物时，整个容器不能点燃，并显示原因。封格不等于锁物。

## 6. 点燃生命周期

可在战斗中一键发动，烧掉当前第一名所属的祭坛物品以换取终极效果；当前第一名所属祭坛物品中有「看门」锁物时不能发动。同一时间只允许一个点燃终极，结束后才可再次点燃。

| 阶段 | 物品与效果 |
| --- | --- |
| 发动 | 按烧毁前状态判定点燃触发效果一次；后续失去加权不会取消已经发动的终极。 |
| 燃烧期间 | 被烧物停止原有属性、持续效果及投票，但仍占原格。其他物品继续争位，显灵与作祟照常。 |
| 通常结束 | 物品成灰，自动移入仓库，无位置则落地；灰可喂饕餮或丢弃，祭坛得以重新构筑。 |
| 残影 | 点燃后永久失去这份传承，不生成可回收灰烬。 |

通常持续 20 秒是原型参数，未作最终平衡承诺。

已确认例外：

- 「镇海」：每件塔·镇物品每局最多免烧一次；仍进入燃烧状态、暂停效果并占格，结束恢复原物。第二次照常烧毁，挪位不刷新次数。
- 「十日」：前 20 秒占终极位置并照常清理物品，之后转为持续到局末的余焰，不再占终极位置，可继续点燃；余焰不重复叠加。

## 7. 装备、符、契与技能

装备在装备区提供属性、身法及普通符效果；上坛后提供投票及明确要求在祭坛生效的符效果，不再提供防御等装备属性、身法、普通符效果或装备／羁绊技能。

每件装备指定一张已嵌入的符为主符，决定唯一容器；其他符保留各自适用的效果，但不增加容器或基础票数。营地可重新指定主符，无需拔符。

契本身正常投票，代价为占两格、影响排名且可能被烧。普通持续效果在契离坛后停止。累计加成依附该件契：离坛暂停但保留计数，重摆恢复，烧毁或丢弃则失去；已结算回血、掉落不追回。明确消耗物品后仍保留的效果须逐项写明例外。

同名符、契效果取最高一份，不重复叠加或触发，除非明确写着可叠加；每件仍各自占格、投票。不同名效果可按规则组合。

技能由有效装备和羁绊自动授予，不存在独立书实物、经脉或额外启用名额。训练弓提供穿透箭／箭雨、布履提供回风，弓＋履羁绊提供蓄势，随行青龙提供引风；固定Q／E／G／T／C。普攻和基础闪避为人物基础操作。

入仓、上坛、落地、烧毁或移除来源后，资格即时失效；同名来源不叠加，换装不刷新冷却。未生效动作取消并退预扣费用，已生效箭和箭雨保留，蓄势余层、对应冲刺与引风追加随来源撤销。完整时序与输入规则见[当前合同](技能来源规则_装备与羁绊.md)。

旧书三选一、类别倾向、双书成型概率及跨局技能池解锁不继续作为要求；当前构筑符奖励保留，不另造替代系统。

## 8. 神兽、金币与强化

神兽及其技能、气息在出发前确定，局内不换。喂食技能等级最多三级，局末清零；跨局亲密度只解锁脾气候选，出发前最多选一个，也可不选。各脾气必须写明行为与代价；喂食数量、主动吞食选物等细节仍需内容规格。

金币只用于营地采购本局物品，局末清零，不替代器魂空间成本；强化与重铸仍用器魂。首关白盒不接商店，商品与价格另行校准。

强化必定成功，品质上限为凡 +3、精 +5、仙 +7、神 +9、专属 +12；低品质按实际可达等级截断。

| 强化段 | 器魂 | 每级消耗 |
| --- | --- | --- |
| +1～+3 | 凡品 | 1／2／3 |
| +4～+6 | 精致 | 2／3／4 |
| +7～+9 | 仙品 | 3／4／5 |
| +10～+12 | 仙品 | 4／5／6 |

只保留三种器魂，不增加神器器魂。每堆 1×1，同品质最多 5 个，不同品质分堆。+0 到 +9 共 27 个，到 +12 共 42 个；一次备齐 +9 的凡 6、精 9、仙 12 共占 7 格，也可分批消耗，不要求囤齐。原稿 45 个／9 格及 1×3 的口径不再使用。

## 9. 局外成长与传承残影

局外解锁新玩法及开局方案；额外优势须占用局内资源或承担明确代价，是否足够须试玩验证。不能仅因为没有直接写攻击百分比，就视为没有强度收益。

| 项目 | 已确认规则 |
| --- | --- |
| 通常数量 | 无名 1／有姓 2／一方 3／真名 3，可选 0 件；旧残影计入同一上限，不逐局额外累加。档位阈值待节奏测试。 |
| 位置 | 保留原物形状，出发前由玩家摆放、可旋转；开局后本局锁定。须实际放得下，否则减少数量。 |
| 能力 | 每件基础 1 票，正常受气息、对冲影响；不能使用、强化或喂兽，可随所属容器点燃。 |
| 信息 | 保留原物种类、品质供记忆及「太仓」使用，各档不再额外限制传承品质。 |
| 结算 | 胜利、阵亡、香尽均可；候选为仍持有且有归属的物品及旧残影，已耗或已烧物不可选。退出、异常中断、被复活救回不算新的传承机会。 |
| 永久失去 | 烧毁或局末不再选择，失去的是这一份传承；不封禁同种物品再掉落或新传承。图鉴记录保留，没有额外跨局残影仓库。 |

相关道具修订：

- 「守灵」只在阵亡结算额外 +1 名额，额外那件须来自阵亡祭坛，仍须放得下；同名不叠加，胜利、香尽、复活救回不触发。
- 「窃国」须在击杀 Boss 时于坛上生效，局末可选 Boss 名字作为 1×1、金·鼎、1 票残影，计通常上限。
- 「太仓」恢复原物种类、品质及基础效果，不恢复上局强化、符或累计计数。恢复装备须按本局重新附魔定归属，未附魔时不再提供原残影的容器票。

## 10. 消耗、保命与战斗边界

器使用一次消耗一件。快捷栏只指向背包实物，不增加储物空间；使用祭坛上的器立即移物、重算票。燃烧物、锁物及残影不可使用。「司晨」每局最多使用三件，换同名器不重置次数。

同次致命伤只触发首个可用保命：**月影 → 替罪 → 朱雀 → 殉葬 → 代死 → 镜中人**。无法支付代价则跳过；有不可烧毁锁物时「代死」不能发动。次数按效果名累计，换物品不刷新各自上限；镜中人是没有其他保命可用时的最后战斗阶段。

战斗效果的“永久”统一写为“本局累计”，局末清零；契仍须在坛生效。「羔羊」等消耗物品换身法保留的例外，写明本局内脱离原装备仍生效，不新增跨局累计战斗属性。

生命上限变化保持当前生命数值，超过新上限才截断，增加上限不补血。营地只预览，离开按最终构筑结算一次。

直接攻击、主动技能可触发命中／暴击词条；词条派生的落雷、燃烧、反伤、爆炸不再触发这类派生。派生伤害仍可产生击杀收益，击杀爆炸可连锁，但每个敌人只结算一次死亡。

普通怪可被成型构筑持续压制；Boss 的持续冻结类效果改为减速，其他硬控暂定单次最多 2 秒，结束后 5 秒硬控免疫，转阶段照常。具体减速、时长及抗性还需效果校准。

「野有死鹿」将本局首次符合条件的可选普通战斗房替换为尸体与线索事件房，不影响精英、Boss、必经剧情，不发原战斗掉落和击杀收益。其避战、省时价值仍需评估，不再称毫无战斗收益。
