道具图鉴

十肖 × 三形制 × 五词缀 = 150 件  +  器魂 3 种  |  配套《基础玩法文档 v0.2》

肉鸽的灵魂是道具，但灵魂不是数量。150 件如果都是同一件东西加了五个数值档，那是 30 件道具和 120 个废物。
所以本图鉴立了一条硬规矩：词缀不是数值递增，是效果本身变了。 残档的「窃粟」偷一枚铜钱，异档的「太仓」把你上一局的残影偷成活物——它们不是一件东西的两个强度，是两件东西。

§ 00三条设计原则

① 每档是不同效果

五档词缀 = 五个不同的效果，不是同一效果 ×1.5。
判定：如果某两档写成「+20% / +40% / +60%」也能成立，那这两档就是偷懒。

② 异档改写规则

最高档「异」几乎不给数值，它给规则改写：改票数、改点燃、改传承、改一个系统的默认行为。
异档是让玩家截图发群里的那一件。

③ 三分之一碰系统

150 件里 39 件会碰到祭坛 / 票数 / 点燃 / 神兽 / 残影。
其余是纯战斗与生存道具——它们负责手感，不负责系统。

三形制

形制形状用法与系统的关系
器1×2投掷 / 消耗，用了就没纯战斗。是道具的"手感层"
符1×1嵌进装备，不可取下嵌了就跟着装备走——换装备时要权衡
契1×2摆在祭坛上，本局持续生效占着祭坛格子 → 带契 = 少一个投票位。这是契的代价

「十日」—— 火焚点燃的最高级，是天上多出一个太阳。

这个游戏叫《十日》。九个太阳已经被射下来了，只剩一个。
而当玩家把火焚推到第一名、再把它烧掉的时候，天上会回到两个太阳。

标题不该只写在封面上。它应该是一件道具的效果。

§ 13化学反应：让道具互相说话

真正让肉鸽被记住的，从来不是某一件道具，而是两件道具撞在一起的那一下。这十条是我设计时就埋好的。

#组合发生了什么
1猴契·镇海 + 塔·镇第一塔镇物品不被点燃消耗 → 可以无限点燃 → 全场敌人永远静止。 这是全套最强的一档组合，也是最难凑的。
2鸡符·十日（异）火焚点燃 → 天上出现第二个太阳 → 全场烧到本局结束。 游戏叫《十日》，这件道具就是标题本身。
3羊契·牂羊坟首 + 羊契·血祠不能回血 + 掉血加攻 + 木祠票数 ×2 → 一个越挨打越强、但一滴血都回不来的流派
4羊符·祠主 + 兔契·镜中缘中央 2×2 ×1.5，对称位票数互通 → 用 8 格养出 16 格的效果，代价是必须严格对称摆放
5猪器·沉渊 + 马符·天罚把敌人吸进归墟 → 落雷劈向血量最高的 → 归墟里的雷伤翻倍（湿润 + 密闭）
6狗符·守灵 + 传承残影死亡时祭坛物品不成灰 → 全部变成下局的残影 → 下一局开局祭坛就满了。是福是祸取决于你摆了什么
7鸡契·焚如 + 火·焚第一所有伤害变燃烧、不能暴击 → 但火焚显灵是「击杀爆炸」 → 于是你走引爆流，全程没有一次暴击
8鼠契·硕鼠 + 点燃每 30 秒洗牌 → 可以算准时间，在洗牌前把最高的那家烧掉。这是本作唯一需要看表的玩法
9鸡符·燔祭 + 饕餮杀敌烧成灰 → 灰喂饕餮 → 饕餮吞灰变强 → 强了杀得更快，灰更多。一个自我加速的循环
10鼠器·太仓 + 任意残影把上一局的残影偷成活物 → 但那件东西一旦被点燃，就永远消失了。 这条链唯一的作用，是让玩家亲手毁掉自己上一局留下的东西
「太仓」让玩家有能力把记忆变回实物。
但变回来的代价是——它会再一次变得可以被烧掉。

而一旦烧掉，连残影都没了。你失去的不是一件道具，是你上一次活着的那段证明。

这条规则不是隐喻。它就是《十日》那句「被记住的才存在」，照着字面实现了一遍。
