# 中断恢复以房间结算点为边界

2026-10-16 已确认：允许退出或异常关闭后继续本局，从最近完成的房间结算点恢复，保留该点的剩余单局时间；未完成的房间重新开始，中断本身不算阵亡。

选择这一边界，是为了支持单局跨多个房间的桌面冒险，同时避免序列化战斗中每颗子弹、动画与敌人瞬时状态的复杂度。它允许重复挑战尚未结算的房间；房间随机结果如何保持一致、主动永久损失何时提交，以及首个房间前的恢复规则仍待后续确认。

Q20 补充：地区 Boss 击败后增加独立的战后检查点。此时停止单局计时，处理奖励与必要签署；中断后返回结算界面而非重打 Boss，完成后才正式结束本局。普通房间仍沿用上述房间结算点规则。

2026-11-09 汤谷补充：Boss 倒下后仍需抵达出口满足胜利条件。此前的战后检查点恢复 Boss 已败的征程，最终结算打开后恢复该界面。正式出征也形成首个检查点。见[安全屋需求](../mvp/局外安全屋_需求与验收.md)。
