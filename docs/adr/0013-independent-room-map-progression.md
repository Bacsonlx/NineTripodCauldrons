# 地图改为独立房间，完成任务后通过门推进

2026-10-21，用户要求将当前连续汤谷地图改为房间形式，保留现有画风；每个房间可有一个或多个出入口，完成该房间任务后解锁通往后续房间的入口。连接方式明确选择“独立房间，过门切换场景”，人物从目标房间对应门内进入。

这一决定取代 [ADR-0009](0009-mvp02-follow-camera-world-space.md) 中连续手工汤谷地图的空间组织安排，保留二维战斗平面、固定等距角度、世界坐标与视口坐标分离等决定。独立房间有明确的任务与切换边界；门不再仅是同一连续地图上的阶段障碍。换房间仍属于同一局，沿用既有“一局／房间”的区分。

后续访谈确认采用互通探索：不同门连接不同房间，可返回已完成房间；任务进行时所有门包含来路封锁，完成后一起开放。战斗房清敌，探索房阅读并合上残碑，安全房直接通行。过门操作为走近按 F，并显示目标房间名称；已完成房间不刷新敌人或一次性互动。

本轮固定七房：入口 → 第一战斗庭 →〔碑林／祭火〕→ 第二战斗庭 → 第三战斗庭 → 终点，两条支路汇合且可回溯。满血不妨碍通过祭火安全房，回血仍可选。新流程已接入默认入口，复用现有素材与战斗；原连续地图保留供历史参照，随机房间、Boss 与正式存档不在本轮。跨房沿用同一局生命与冷却，R 继续重开整段流程。
