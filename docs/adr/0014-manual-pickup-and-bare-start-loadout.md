# 开局只带基线装备与神兽，战斗拾取改为按 F 手动

2026-11-12，用户指出「掉落道具的拾取放入背包还存在问题」，并明确「初始状态下人物应该是没有道具的，道具的拾取需要重新进行设计」。这两件事指向同一处矛盾：拾取原本是自动的（地面构筑实物一进入半径就每帧被吸进收纳区），玩家既没有拒绝权，也看不到「要不要捡」这个决策；而与此同时 `AlphaState.reset()` 又写死发放六件起始物品，其中三件生肖道具直接占着收纳区，使「开局有什么」既不由玩家决定、也不符合叙事上「刚从泗水捡到青铜碎片的孩子」的处境。

决定如下。

**起始构筑收窄为「装备区基线装备 + 神兽」**：训练弓、布履、青龙保留在装备区默认格位，祭坛与收纳区开局全空，不发放任何生肖道具（符、器、契）。保留基线装备的原因是结构性的，不是宽容：符必须嵌入装备且装备有效穿戴才生效，而当前掉落池八件全部是符，一件装备都没有；若连装备一并清空，玩家捡到的符无处可嵌，等于开局无构筑可建。神兽同样保留，因为它的 2×2 占格是气息加权的空间来源（见 ADR-0011 与 Q30／Q45），移出背包则气息机制失效。

**拾取改为按 `F` 手动**：构筑实物与药瓶共用同一条 `F` 交互链路，走近时高亮提示，按键才收取。构筑实物收取后落入收纳区；收纳区无合法空位则留在地面并提示，不替换、不丢弃、不移动已有物品。这一条取代 Q49「战斗拾取默认自动入仓」的默认自动部分，保留其「快捷改放祭坛」与「精细调整留在营地」两段。

**恢复「一次快捷改放祭坛」的原义**：`Tab` 只在刚按 `F` 拾起某件实物后的三秒窗口内有效，且只作用于那一件；系统在祭坛 16 格内寻找能放下的位置与朝向，放不下则实物留在原处。此前实现的拾取卡会被后续每一轮自动拾取重置、并指向「本批第一件」，与规则描述不符，一并纠正。

**空快照与未设快照必须区分**：`R` 重试与阵亡重开恢复的是出发时的背包快照。起始构筑收窄后，空手是合法开局，因此「快照为空」不能继续被当作「未设置快照」而回退到内置默认物品；出发时须显式记录空快照。

首页与安全屋两条入局路径共用同一份起始构筑定义，避免出现首页空手、安全屋仍发六件的两套开局。
