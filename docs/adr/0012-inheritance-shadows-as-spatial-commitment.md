# 传承残影保留记忆，以锁定空间承担跨局优势的代价

2026-10-20 用户在六器系统访谈 Q28—Q31 确认：传承残影保留原物种类、品质信息与占格形状，基础票数统一为 1，仍受气息加权及对冲影响。采用固定票权而非按原品质保留 1～4 票，是为了让传承主要保留构筑倾向，避免高品质记忆直接变成后续每局更高的起步票数；高品质信息仍可用于「太仓」恢复实物。

玩家在出发前主动选择位置并可旋转，开局后本局锁定，选中物品必须实际放得下。以主动承诺空间代替系统随机放置，使代价来自选择而非坏运气。无名／有姓／一方／真名的通常上限为 1／2／3／3 件，可选择不带；旧残影计入同一上限，胜利、阵亡、香尽均可在正式局末重新选择。被消耗或烧毁的物品不能再选，退出与复活不产生额外传承机会。「守灵」「窃国」「太仓」及永久失去的具体边界，见[玩法确认记录](../product/十日_玩法与运行规则.md) Q60—Q63。
