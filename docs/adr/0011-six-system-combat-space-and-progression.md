# 六器构筑以战斗为主、空间真实邻接、局外优势承担代价

2026-10-20 用户在六器系统访谈第一轮确认：战斗主导，背包构筑改变战斗方式；战斗拾取采用简单快捷取舍，超时自动入仓，精细整理放在安全营地。“每次拾取都形成三秒决策”保留为待验证假设，避免在尚未验证节奏前固定每次拾取的注意力成本。

神兽气息由背包中的真实空间距离决定覆盖，接受为此调整区域布局，不采用独立指定祭坛加权区。选择真实邻接，是为了让神兽的位置与其他物品共享空间取舍；后续确认的白盒布局及加权规则见[玩法确认记录](../product/十日_玩法与运行规则.md) Q44—Q47，尚待玩法验证。

同日后续确认：气息只加权同容器物品，饕餮不挑食仅是喂食例外。点燃可在战斗中一键发动，不打开背包或暂停；被烧物品立即失去投票，效果期间占据原格，结束后灰烬自动入仓，无空位则落地，并可喂饕餮或丢弃。这样保留点燃的占位成本，同时让祭坛能够在单局内继续构筑；20 秒为待试玩调校的原型参数。契本身投票，离开祭坛后停止普通持续效果，累计收益及特殊例外以[主干确认稿](../product/九鼎_六器系统_玩法主干确认稿_v0.3.md)为准。

局外成长采用“解锁玩法与开局方案，额外优势占用局内资源或承担明确代价”的原则，取代基础玩法文档中“局外绝不影响战斗数值”的绝对限制。残影占位和神兽新行为仍可能提高实战能力，不能仅因没有直接增加攻击百分比就视为没有强度收益；具体代价需要试玩验证。该决定属于后续完整玩法设计，不自动扩大已有 MVP 或 Godot 迁移验收范围。
