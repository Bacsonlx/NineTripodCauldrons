# 汤谷首关地图：独立环境资产搭建

> 2026-10-21 后续更新：当前默认已改为[七房间互通流程](汤谷房间地图使用说明.md)。下文记录保留的连续地图及其制作历史，原场景未覆盖。

2026-10-21，用户要求解决整张原画放大导致的模糊、建筑不能单独编辑的问题，并默认进入新地图。当前运行地图采用原生 Godot 2D 分层场景，沿用高保真 0.2 的空间布局，以独立地面、圆庭、门楼、石墙、营地、树根、植被和岩岸重新搭建。完整原画及其裁片已从运行场景移除。

## 截图反馈修正（2026-10-21）

- 道路与林地不再用不透明多边形硬切：`Ground` 使用原生绘制的约42像素碎边渐变，仅沿整个路网的外边界生成，路口交接处不夹入林地条缝。可走区域保持独立，视觉过渡带不额外扩大可走范围。
- 移除七处圆庭内部墙柱，侵入石盘的边墙和火柱移到圆盘外缘；四处圆形战斗地面中央保持净空。
- 入口门镜像转向道路，柱脚同步转向；出生位置调整到门洞正前方 `(540,2380)`，前方可直接走出。门的深度偏移用于避免门梁盖住门前人物。
- `Ground` 的 `Blend Width` 可调过渡宽度；编辑子地面多边形会自动重建外缘。节点保留在场景中供编辑，运行时由统一地表绘制代替它们的不透明材质切边。

新增9项截图问题回归，覆盖四庭净空、门前直行、门洞前方出生与连续外边界；[本轮验证记录](../../output/level-design/tanggu-world-fixes-20261021/verification.json)。仅后台验证，原生画面仍由用户试玩确认。

## 环境融合修订（2026-10-21）

- 独立建筑下新增 `GroundContact`：使用现有林地材质生成苔土过渡，以及软接触阴影。边缘透明，跟随父建筑移动、缩放与显隐；不添加碰撞。地面层级固定在圆庭以上、人物以下，圆庭自身不生成接地覆盖。
- 石墙、门楼、火柱、残碑与祭火统一为较暗的灰绿石材色调；营地降低红布和木料的突兀亮度，火柱闪动仍保留基础色调。
- 两处纵向封路各采用补绘的完整纵向残墙，替换十二个多余短墙实例；横向封路调整地面投影，使墙基衔接。实体封路的位置、尺寸和清场解除条件保持原值。
- `Ground Axis` 仅控制美术的地面投影，竖直方向不旋转；日常摆放继续移动整个父节点。`GroundContact` 为脚本生成，不要单独修改其子多边形。

[同位置前后对照](../../output/level-design/tanggu-grounding-20261021/index.html)；新素材的[提示词与来源](../../output/art/TANGGU-WALL/2026-10-21-v2/generation.json)。当前 16 项地图修订检查中包含 7 项接地／连续墙回归。修改前后导出的规则布局（不含纯呈现 groundPatches）逐字段相等。构建、干净导入、包加载和待验边界见[本轮验证](../../output/level-design/tanggu-grounding-20261021/verification.json)。

## 运行与编辑

```sh
godot --path godot
godot --editor --path godot
```

启动后直接进入汤谷新地图，无需切换实验地图。M 或右上角“地图总览”切换完整地图／角色跟随；切换清除当前移动、射击意图。

- 运行入口：[tanggu_first_level.tscn](../../godot/scenes/tanggu_first_level.tscn)。
- 当前地图：[tanggu_first_level_map.tscn](../../godot/scenes/tanggu_first_level_map.tscn)，世界 4608×3072。
- 旧 [tanggu_map.tscn](../../godot/scenes/tanggu_map.tscn) 保留用户编辑结果，作为历史地图，不再默认运行。旧白盒／地图场景可由开发者明确打开，当前玩家界面没有它们的入口。
- 地图中有 507 个独立环境实例，来自 [environment_prop.tscn](../../godot/scenes/world/environment_prop.tscn)。单个节点承载美术、位置、占地、阻箭高度与清场条件。直接移动节点；不要通过修改纹理偏移替代移动建筑。
- 在 Inspector 调整 `Texture Asset`、`Render Width`、`Position`；实体使用 `Category=obstacle`、`Size`、`Body Height`。`Sprite` 子节点显示实际素材；按脚点深度遮挡，玩家在物件背后时减淡。
- 残碑、祭火和回程门各有 `InteractionAnchor` 子节点。移动建筑同步移动美术、碰撞和互动点；改变操作站位时移动子锚点。顶层旧 `Interact_*` 仅供兼容布局数量校验，运行坐标以建筑锚点为准。
- `Ground` 中材质 Polygon2D 决定可见地面，`Walkable` 中 19 个多边形决定可走范围；编辑通路需同步修改两处。`Region_*` 只提供 HUD 区域信息。
- 门楼通过两个柱脚子实体保留中央过道；营地的支杆与铺盖有独立子实体，火柱实体阻挡移动和箭。移动父建筑时子实体一起移动。
- 三组影偶保留 3／4／5 出生配置。三段出口封锁与清场状态同步解除，重试恢复；回程门从南侧内侧安全开启。

首次搭建工具 [build_tanggu_world.py](../../tools/level_design/build_tanggu_world.py) 只允许输出到新文件。场景已生成后由编辑器维护，不能重跑生成器覆盖用户调整。来源描边见 [tanggu_reference_layout.json](../../tools/level_design/tanggu_reference_layout.json)。先前两个 `prepare_*first_level/reference_level*` 工具仅对应历史灰盒／原画底图。

## 素材与分辨率

运行素材在 [godot/assets/world](../../godot/assets/world/atlas.json)，原始生成物和提示词见 [素材记录](../../output/art/TANGGU-WORLD/2026-10-21-v1/generation.json)。全部生成经内置 image_gen，不调用付费 API 或视频服务。

- 地面：1254×1254 材质图集，Godot 无损提取为四张 627×627 材质，按世界单位 1:1 平铺，不拉伸整图。
- 圆庭：1585×992 独立底图，实际区域 1546×960；四处圆庭显示宽度 810—1080 世界单位。
- 中央树根：1254×1254；树木各为独立 1254×1254 原图；火柱独立 1024×1536。透明边通过 AtlasTexture 区域读取，没有插值放大素材。
- 门楼、两方向石墙、营地、祭火来自建筑图集，岩石、蕨类、残碑和地被来自环境图集。所有环境实例在 1280×720 设计视口下按原生像素或缩小显示；高 DPI／超大窗口仍由相机和显示缩放决定最终像素密度。

画风与构图以 0.2 为方向，但这是独立素材重建，不能声称与生成原图逐像素一致。当前火焰使用静图与亮度变化，尚无完整火焰帧动画。地图实际画面、材质接缝、遮挡与前台性能仍待用户安排原生窗口验收。

## 玩法范围

本轮是地图制作和默认入口切换，复用既有跑射、技能、受击、重试、残碑、一次回血和门禁。营地构筑、Boss、奖励与结算未因此实现，继续按[首关 Spec](../mvp/九鼎_汤谷初版_人物道具技能_Spec_v0.1.md)推进；不改变白盒确认门。
