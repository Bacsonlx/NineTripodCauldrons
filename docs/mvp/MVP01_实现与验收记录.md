# MVP-01 实现与验收记录

2026-10-16。依据 [Spec #1](https://github.com/Bacsonlx/NineTripodCauldrons/issues/1)。实现范围为汤谷单房间跑动、独立瞄准和射箭，不包含 Boss、剧情与存档。

用户确认先生成 Windows x64 ZIP，随后在 Windows 实机验收。因此 Spec #1 保持未完成，不以 macOS 结果或 Windows 构建成功代替 Windows 实测。

## 当前实现

- WASD 屏幕方向移动、斜向归一、松键停止、柱基阻挡与沿边滑行。
- 鼠标 360° 瞄准、方向近零保留、四向人物显示带滞回；短按一箭，按住以 0.35 秒间隔发起攻击，拉弦 0.08 秒，普通松手完成已开始的一箭。
- 箭沿瞄准方向以 700 设计像素／秒运动，线段检测最早接触，最长 2 秒；柱身与靶面使用独立于脚点通行的区域，弓口生成前也检查阻挡。
- 一玩家、三柱、两靶；命中一次计数，靶闪色 0.10 秒，局部火花 0.15 秒。箭与效果及时清理。
- Esc 暂停／恢复、失焦暂停、清输入、取消未发箭；运行中 R 重置；移出画面清连射并取消未发箭，返回后需重新按下。
- 1280×720 内部画布，等比适配留边；必要素材加载失败显示提示。F1 临时显示碰撞区域，正常默认隐藏。

## 人物与武器精修

用户要求提升初稿质量后，以已选概念图为风格参考，通过内置 imagegen 制作透明 PNG：同一个黑发束髻孩子，米白交领布衣、靛蓝裤、朱红长巾，配木弓、铜饰、缠布和羽箭。

当前人物为四方向×四姿态样例（待机、两个跨步、拉弦），运行时使用裁切矩形与逐帧脚点，没有新增骨骼运行时。跑动时保留步态，用独立弓箭叠层显示攻击；站立射击用拉弦姿态。人物与弓箭已接入实际房间。精修图替换仅涉及玩家和武器，场景柱与地面仍为本项目程序绘制的 SVG。

这套素材用于画风与动作评审，尚有两个明确限制：只有两个跨步关键帧，连续跑动的过渡不够丰富；四向身体与连续旋转弓的握点是近似对位，斜向与反向跑射仍需逐方向精修，开弓暂以持箭与轻微形变反馈。不得标记 AC-18 正式美术验收通过。

图集、透明源图、实际尺寸、裁切和握点、完整提示词见 [精修制作说明](../../assets/mvp/精修制作说明_v2.md)。原 SVG 占位版本及其生成脚本保留，方便对照阶段 A。

## Windows 实机验收步骤

1. 解压完整 Windows ZIP 到本地目录，运行 `nine-tripod-cauldrons.exe`；不要只复制 exe。
2. 记录 Windows 版本、CPU、GPU、内存、刷新率、屏幕缩放与 ZIP 名称。先按 WASD 和鼠标确认一玩家三柱两靶、无素材丢失。
3. 按 [Spec](九鼎_MVP01_Spec.md) 的 AC-01—AC-16 逐项验证，特别检查左右／上下反向跑射、贴柱、缩放和留边、Alt-Tab 后仍暂停、Esc 恢复不粘键、按住鼠标离开画面再返回不续射、R 重置 20 次。
4. 将内容输出设为 1920×1080，预热后前台连续跑射 60 秒。保存完整帧间隔数据，平均至少 58 FPS，至少 95% 帧间隔不超过 20 ms；采样被暂停或切窗口打断时重新采满，不能删除慢帧。
5. 另连续操作 5 分钟，检查无崩溃／卡死、箭和火花能清理，记录内存趋势；补充人物动作和持弓观感评审。
6. 回传结果、截图／录屏和数据；失败项保持待修，不关闭 Spec #1。
