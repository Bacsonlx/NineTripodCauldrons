# MVP-02：汤谷大地图、全屏与弓箭战斗切片（macOS／Windows）

## Problem Statement

《九鼎》（副 IP《十日》）已有单屏跑动与射箭练习场及人物分层素材样例，但场景面积和环境细节有限，步态仍以少量关键姿态切换，只有静态靶与命中计数。玩家无法在更大空间中探索，也无法验证技能搭配、受击、闪避和敌人交互。窗口尚未提供默认最大化、全屏切换及任意比例铺满体验。

用户需要在已选的皮影木刻与像素质感方向上，做一个规模受控、能够实际操作的汤谷战斗切片：扩大地图，精修背景、角色、武器与特效，并让技能有明确用途。现有概念图、资产登记和旧版本检查不能证明这些目标已实现。

## Solution

制作一张连续手工汤谷地图，宽高各约为 MVP-01 的两倍，形成安全起点、残垣廊道与战斗庭院。保持固定等距角度，镜头跟随人物并限制在地图内。窗口默认最大化，可切换与退出全屏；画面铺满内容区，人物不拉伸，按窗口比例调整可见世界范围。

仍操作同一个孩子，采用四向精修姿态、八方向移动和 360° 瞄准。固定配置为左键普通箭、Q 穿透箭、E 固定范围箭雨、空格闪避，技能仅使用冷却。面对一种近战影偶，沿路线依次激活三组遭遇，初始数量为 2／3／4；玩家会受伤、失败并从起点重试，清敌后可继续探索和练习。

先确认现有运行基线，再验证占位功能与动作小样，最后接入代表美术并复验。必须交付 macOS Apple Silicon 与 Windows x64 ZIP，以及各自的实际运行、动态画风和性能记录。Windows 可先交付 ZIP 供用户随后实机验收；在该端结果回来前保留未完成状态。

## Implementation Decisions

### 现有基础与范围关系

- 沿用 TypeScript、Phaser 3.90.0 WebGL、Electron 44.8.0、Forge／Webpack 与受限 preload；本规格不升级或替换技术栈，不引入专用骨骼动画运行时、数据库或逐帧 IPC。
- 已有入口是 1280×720 单屏、一个玩家、三柱、两静态靶；存在公开的房间输入、时间推进和可观察状态，以及场景与桌面窗口。已有普通箭、首次接触、暂停和重置可复用，不从零另造引擎。
- 工作区已有四向上身与下身分层、三态弓及 15 项房间行为测试用例；下身仍只有两个跨步关键帧。当前没有大地图、跟随镜头、敌人、生命或主动技能系统。现有素材样例与旧检查不算本规格的实现或验收结果。
- 先重新验证当前分层场景的实际运行与输入基线，消除未收束的集成问题，再扩展。MVP-01 #1 保持独立，不关闭或改写其历史结果，也不要求先关闭 #1 才能开展 MVP-02；缺失的平台验证不能被跳过后称为完成。
- 游戏规则、输入、敌人、碰撞、技能与渲染在游戏窗口协作；桌面侧只处理窗口、全屏等低频系统能力。扩展现有规则和场景职责，保持可通过输入推进并观察外部状态，不预建大型实体框架。

### 世界、镜头与窗口

- 单张连续手工汤谷地图，参考世界范围约 2560×1440，相对旧世界宽高各约两倍。名义面积约四倍，实际可走范围由通路与障碍布局确定；不是将旧地图拉伸放大，也不是新增地区或多房间系统。
- 路线包含安全起点、残垣廊道、战斗庭院，配石庭／焦土变化、残墙、石柱、扶桑树与树根、日鸟祭坛、远景及少量环境动态。安全起点无敌人出生，不另建永久保护区规则。
- 地面、远景、实体物件、树冠／前景遮挡、角色、箭、特效和 HUD 独立。装饰不自动成为碰撞体；实体通行、可见阻箭区域和排序脚点必须明确。祭坛只作场景物件，不新增上香或剧情交互。
- 保持固定等距投影角度和二维战斗平面。镜头仅跟随玩家，不旋转、不按鼠标偏移、不引入真实高低差；在地图边缘夹紧，缓动可调，不暴露场景外空白。
- 明确区分世界、视口和窗口：移动、敌人、握点、弹道、落点和碰撞使用世界坐标；指针从内容区经相机换算为世界位置，HUD 使用屏幕空间。即使指针没有移动，相机移动时也要重新换算当前屏幕位置。
- 默认最大化启动，提供明确的全屏／退出全屏操作；Esc 保留暂停／恢复含义，不用一次操作同时执行暂停和全屏切换。窗口控制不得落成游戏射击或施法。
- 画面铺满可用内容区，不强制 16:9 黑边，不拉伸人物。参考构图为 1280×720，非 16:9 按比例调整可见世界范围，超宽屏允许多看到横向地图；地图仍需覆盖视野。窗口变化不能改变世界移动速度、技能范围或伤害。
- 全屏切换若触发失焦，沿用失焦暂停规则，不擅自恢复或补发；重新映射指针、调整相机边界与 HUD，并清除不再合法的输入。

### 玩家与基本射箭

- 同一个孩子、后羿弓，浅衣、靛裤、朱红长巾；四向精修姿态支持八方向移动和 360° 真实弹道。身体方向数不限制瞄准角度。
- WASD 按屏幕方向移动，斜向归一，相反输入抵消，松键立即停止；起停动画不引入惯性。脚点受边界与实体障碍限制，可沿阻挡面滑行；完全受阻时不持续原地跑步。
- 移动与瞄准独立；原地绕身和反向跑射稳定，近零瞄准保留上次有效方向，方向分界不抖动。弓围绕可见握点旋转，箭从对应释放点出发；贴墙柱先检查身体参考到释放点之间的阻挡，不能在障碍另一侧生成箭。
- 左键可攻击时短按一箭，按住按固定间隔连射。普通松手完成已经开始的一箭并停止后续连射；间隔内短按忽略、不排队。保持拉弦、放箭、收势表现，放箭时使用当前有效瞄准。
- 普通箭直线运动，遇第一个敌人、实体障碍或边界结束，不穿透或反弹。碰撞按运动轨迹检查首次接触，不能单帧跨过薄目标；每箭对命中敌人一次结算。
- 箭离界、命中或达到最长存续后清理；没有落地箭、回收、弹药、暴击或装备词条。普通箭与技能只伤敌人，不新增己方范围自伤。

### 固定技能组

| 输入 | 技能 | 硬性规则 |
| --- | --- | --- |
| Q | 穿透箭 | 短前摇后发一支直线强箭，不蓄力，可移动施放，释放时取当前有效瞄准；可贯穿多个敌人，每敌每箭最多一次；仍被墙、柱、实体障碍和边界阻挡 |
| E | 箭雨 | 受理时取鼠标地面落点并检查施法距离与区域合法性；金色预告后在固定范围分段落箭，不随鼠标或人物移动；可越过低矮障碍，不增加射手到落点的直线视线限制 |
| 空格 | 闪避 | 有移动输入则按移动方向，无移动输入则按最后有效瞄准方向；短距离位移、短暂无敌、可穿敌但不能穿墙柱；途中不能攻击，有独立冷却 |

- Q／E 只响应新按下，按住不重复；仅技能冷却，不增加蓝量、技能树、装配界面或充能层数。
- 普攻、Q、E 同时只允许发起一种攻击；不缓存前摇、冷却或其他不合法时刻的按键，不在空闲后补发。正常技能前摇不锁住 WASD 移动。
- 技能被合法受理即开始冷却，受击或闪避打断不返还；无效落点、冷却中、暂停或其他未受理输入不扣冷却。
- 箭雨地图外、不可站立或超距离落点明确显示不可用，不能悄悄夹到另一个点再施放。合法落点受理后固定，正常移动不重新选点；前摇预告不算已生效伤害区域。
- 箭雨前摇被打断时取消预告，不返还冷却；开始落箭后才作为持续技能处理。每一段对范围内同一敌人最多结算一次，不将每张视觉落箭重复当作一次伤害。范围按敌人脚点判断，地图边缘不伤到地图外。
- 穿透箭按轨迹顺序处理障碍与敌人，只伤到阻挡前的敌人；同一敌人的去重不影响箭继续命中其他敌人。箭雨视觉可表现从上方落下，但不新增三维高度、跨层目标或新的地形系统。
- 闪避途中禁止任何攻击起手；无敌是规则时间窗，与透明度或动画帧无关。位移检查沿途障碍，不能靠终点不重叠来穿薄墙；结束位置必须合法。

### 受击、打断与优先级

- 玩家有生命，受击有明确反馈、短硬直和短暂保护。同一挥击不能每帧扣血；保护窗内不重复受伤，闪避无敌窗与受击保护分别管理。
- 受击打断尚未释放的普通攻击、穿透箭和箭雨前摇；受击硬直中不能攻击或发起闪避。闪避可取消自身未释放攻击，不能从受击硬直中立即启动。
- 已飞出的箭、已经开始落箭的箭雨不因施法者普通受击而消失。暂停或失败冻结这些对象；重试才全部清理。
- 规则优先级必须保证暂停／失败冻结优先、有效受击能取消未发动作、闪避期间无敌且不能攻击、每次只接受一种攻击。相同推进中不得同时显示失败与完成；玩家生命归零时按失败处理。
- 命中、无敌、生效和打断由战斗规则决定，不靠显示帧回调重复出箭或扣血。敌人受击表现不能隐式改变已经约定的攻击判定。

### 影偶、遭遇与重试

- 只做一款基础近战影偶，正式故事身份不在此规格内定案。必要状态为未激活／待机、接近、预警、挥击、恢复、死亡；配受击表现和生命反馈。
- 已激活影偶追击玩家，能绕开残墙、石柱与树根，不能长期卡在一条直线上的障碍后、穿墙或离开可走区域。避免持续完全重叠，不因碰撞将玩家挤出地图；不引入复杂刚体推挤系统。
- 敌人身体接触不伤人，只在有效挥击区域和时间内伤害。预警开始锁定朝向，挥击不跟踪玩家转向；朱红预警与实际区域对齐，恢复阶段可辨认。
- 三组固定遭遇，初始数量为 2／3／4，进入路线区域时激活；同组全部死亡后才允许推进下一组，未激活组不提前追击，不无限刷新。已激活敌人可追击，不能因临时离开视野而重生或重新计数。
- 清敌进度由敌人实际死亡确认，每个实例只结算一次；不能因为躲开、走远或对象暂时不显示而完成遭遇。出生点、触发区与路线必须通过实际通路检查。
- 最后一组清完提示切片完成，不发奖励、不写正式神降进度。完成后可继续自由走动与练习技能，按 R 从起点重试。
- 玩家生命归零进入失败，冻结战斗，停止移动与攻击，明确提示 R 重试。R 重置生命、冷却、敌人、三组进度、未发动作、箭雨预告／区域、箭、特效、保护状态与输入，并将人物和镜头归位。
- R 在运行、完成或失败状态可重试，用户主动暂停时不生效；按住不反复重置。重开应用回到初始切片，不读取或写入练习进度。

### 输入、暂停、HUD 与失败处理

- Esc 暂停／恢复；失焦自动暂停，返回仍需手动恢复。暂停冻结移动、敌人、前摇以外已生效对象、效果、保护窗和冷却；取消未释放攻击、清输入，恢复需新输入，不自行续跑、连射或闪避。
- 指针离开有效游戏画面时取消未发普通箭及 Q／E，停止旧的按住连射，已飞箭与已生效区域在未暂停时继续。重入后重新按下才能射击；键盘移动及合法闪避仍可使用，沿用最后有效朝向。
- 鼠标指向 HUD 的可交互窗口控件时，不同时视为射击或施法；显示控件与游戏指针映射共同适配窗口比例。
- HUD 仅保留玩家生命、简洁敌人血条、Q／E／闪避图标与冷却／不可用表现、遭遇进度、操作提示和全屏入口；暂停、失败、完成共用基础提示样式，不新增完整菜单或物品页。
- 必要素材加载中不接受战斗输入，加载失败明确提示并停止进入半失效场景。游戏运行资源全部本地加载；解压最终 ZIP 后离线可进入切片。
- 重试、重进场景或应用恢复不得累加事件监听、旧攻击区域、箭或特效。临时调试可查看脚点、阻挡与伤害范围，正常默认隐藏，不将未收尾诊断入口作为产品功能。

## Testing Decisions

### 已确认的主要测试入口

用户已确认以真实键鼠操作、地图与镜头、技能战斗及全屏切换的外部结果为主要验收入口。自动化优先扩展现有房间的输入→时间推进→可观察结果入口，覆盖生命、冷却、箭、区域、敌人、遭遇、暂停与重试；实际 Electron 场景负责验证输入接线、相机映射、资源和窗口流程。

已有 15 项房间行为用例涵盖跑动、首次接触、普通射箭、暂停与重置等，是复用先例；本规格新增功能尚无通过结果。测试不调用私有碰撞函数、不模拟返回成功，不以标题截图、类型检查、孤立原画或构建成功替代玩法、美术和平台验收。

先验证现有基线和占位功能，再接入人物、环境与技能代表素材；接入后复验受影响行为及性能。人工观感项保留截图／录屏和结论，不伪装成自动化已证明。
