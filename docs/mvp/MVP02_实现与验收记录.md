## 当前实现

- 单张 2560×1440 手工汤谷，安全起点、残垣廊道、战斗庭院；树木、树根、墙、柱和日鸟祭坛独立放置、脚点排序与遮挡淡化。
- 跟随镜头、边缘限位；每帧把静止屏幕指针转换为当前世界坐标。默认最大化，原生全屏／退出与任意比例铺满；HUD 保持屏幕空间。
- WASD 归一移动、立即停止、柱／墙阻挡与滑行；上下身分层，四向各 7 帧跑步、待机、起停与换向过渡、完整普攻、技能、受击、保护和四向跪地失败姿态。
- 普通箭第一接触停止；Q 贯穿每个影偶一次但被实体阻断；E 合法固定地面点预告并三段生效，无效点不扣冷却；空格闪避穿敌不穿墙，独立无敌窗与冷却。
- 影偶接近、预警锁向、挥击、恢复与消散；栅格绕障与局部避让。接触不伤人。三组 2／3／4 依次推进，生命归零优先失败；完成后继续探索，R 重置整轮，暂停中 R 无效。
- 攻击互斥、不缓存输入，Q／E 按住不连发；技能受理扣冷却，被打断不退还。受击打断未发动作，硬直禁止攻击／闪避；已生效对象继续，暂停／失败冻结，R 清理。
- 19 个资产组的实际映射、原始 PNG、裁切／脚点／腰带／握点与完整提示词见 [美术接入记录](../../assets/mvp02/制作与接入记录.md)。未增加剧情、Boss、装备、音频、存档或骨骼运行时。

## 可调初值

沿用父规格：跑速 220，生命 100，受击硬直／保护 0.12／0.60 秒；普攻 15、0.08 秒前摇、0.35 秒起点间隔，箭速 700／2 秒；Q 40、4 秒冷却、0.18 秒前摇与 0.12 秒收势，900／1.4 秒；E 8 秒冷却、0.45 秒前摇、480 距离、110 半径、3×15 伤害、0.18 秒段间隔；闪避 120 距离／0.20 秒、起始 0.12 秒无敌、1 秒冷却。影偶 60 生命、120 跑速，0.45／0.10／0.65 秒预警／挥击／恢复，70 距离、90°、20 伤害。

镜头使用即时固定中心跟随与边缘限位；窗口高度以 720 世界单位为参考，超宽增加横向可见范围，极端比例优先避免地图外空白。输入、握点与弹道使用同一视口变换。新生箭与箭雨仅推进跨过前摇后的时间余量；闪避结束后的普通移动余量保留，无敌按规则时间判断。移动与战斗共用最多 0.01 秒的短时间步，敌人阶段保留跨界余量；箭的碰撞轨迹限制到剩余寿命；暂停中断剩余闪避位移、保留冷却。

## 双平台验收步骤

1. 解压对应 ZIP 的完整内容，离线启动；Windows 运行 `nine-tripod-cauldrons.exe`，Mac 运行 `九鼎.app`。记录 ZIP、源码指纹、系统、CPU／GPU、内存、显示刷新率与缩放。
2. 验证出生点安全、路线可绕行、镜头跟随／边界和静止鼠标瞄准；短按／按住、反向跑射、贴墙与绕柱射箭。按父规格 AC-01—AC-30 逐项记录实际结果。
3. 验证 Q 多敌只命中一次与实体阻挡；E 固定预告、三段伤害、越低矮障碍、无效落点不扣冷却；闪避方向、敌我穿行、墙柱阻挡及无敌窗内外。验证受击与闪避打断、攻击互斥、按住 Q／E 不连发。
4. 沿路线清除三组影偶，确认未激活组不提前追击、预警不跟踪、无接触伤害；死亡、完成与运行状态分别 R；重复 20 次，无旧箭／区域／反馈或监听累积。
5. Esc 与真实切出窗口后恢复仍需新输入；画外／全屏按钮不误射。测试最大化、普通、4:3、超宽、全屏与退出，人物不拉伸、HUD 和瞄准正确。Windows 用 F11 或按钮，Mac 用 Control＋Command＋F 或按钮。
6. 人工评审四向连续动作、脚点、腰带、前手与弓箭、失败姿态、影偶动作、树墙遮挡及双方特效可读性；保留截图／录屏和未通过项。
7. 最终产物输出 1920×1080，记录内部画布与 DPI。加载并预热后，在有活动影偶的真实前台连续跑射、施放全部技能 60 秒；平均至少 58 FPS，至少 95% 有效呈现帧间隔不超过 20ms。另做 5 分钟稳定性操作。中断时保留原因并重新采满，不能删慢帧或关闭正常逻辑／效果。
8. 回传逐项结果、截图／录屏、完整帧数据／compositor trace、对象清理观察与内存趋势。失败项保持待修；Windows 未完成前不关闭 Spec #2。

## 可复核采样工具

`scripts/capture-frame-timing.cjs` 是独立开发验收工具，不是产品菜单或持久化诊断入口。运行中的游戏需使用 `--remote-debugging-port=9335` 启动；采样工具使用 Node 22+，也可通过产物的 Electron Node 模式独立运行。

```sh
node scripts/capture-frame-timing.cjs --port 9335 --delay 10 --seconds 60 --out output/mvp02-validation/performance.json
node scripts/capture-frame-timing.cjs --port 9335 --delay 10 --seconds 300 --out output/mvp02-validation/stability.json
```

十秒准备时间后需真实回到游戏前台。采样保留全部逐帧回调间隔和原始 Chromium compositor trace、焦点／暂停／重试／尺寸中断、画布／DPI 及堆内存趋势；不覆写焦点，不暂停敌人，不删除慢帧。回调指标须结合 compositor trace、实际场景和人工结果复核，不能单独自动宣称平台验收通过。当前 Mac 锁定期间没有生成通过的性能记录。
