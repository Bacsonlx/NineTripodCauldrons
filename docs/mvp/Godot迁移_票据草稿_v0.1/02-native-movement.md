## Parent

[Godot 迁移规格 #33](https://github.com/Bacsonlx/NineTripodCauldrons/issues/33)

## What to build

在 Godot 中离线运行一个复用现有角色素材的小场景，玩家能移动、独立瞄准、绕过障碍并看到正确的跟随镜头，且两平台最小包实际可启动。

## Acceptance criteria

- [ ] 采用官方 Godot 原生 2D 与带类型 GDScript，核实并锁定稳定引擎、匹配模板和候选渲染器，记录版本与校验。
- [ ] 复用既有实际素材与帧元数据建立最小转换链，保留脚点、方向、锚点及缩放；缺失、越界、重复帧或非法数值明确报错，重复转换一致。
- [ ] WASD 单轴与斜向移动、松键停止、鼠标独立瞄准和基本阻挡有可玩画面及规则测试，相机变换和边界沿用参照。
- [ ] 在干净环境导入、解析资源及运行已接入行为测试，有成功／失败退出结果；导出 Windows x64 与 macOS arm64 最小运行包。
- [ ] 两平台指定实机分别启动并加载角色与场景，离线可操作；未取得的原生启动证据保持待验，本票完整完成前必须补齐。
- [ ] 记录 Steam 接入的当前维护源、许可、候选方式与双平台兼容证据／待验证项；不接完整 SDK，不把 Steam 账号或插件准备作为离线切片运行前提。
- [ ] 保持旧版主入口与参照可用，Godot 世界单位不再叠加等距投影，Node.js 仅用于制作工具。

验收追踪：AC-02、AC-03、AC-06、AC-21、AC-22、AC-27。实现遵循父规格已确认的规则、输入适配和原生体验三个测试边界；本票涉及行为与画面一起验证。
