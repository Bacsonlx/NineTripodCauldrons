## Parent

[Godot 迁移规格 #33](https://github.com/Bacsonlx/NineTripodCauldrons/issues/33)

## What to build

玩家能在已确认小样中使用 Q 贯穿多个影偶，看到可辨的聚光、箭迹与命中反馈，并被实体正确阻断。

## Acceptance criteria

- [ ] 前摇、冷却、恢复、伤害与击退沿用冻结参照；同一箭对每个敌人仅产生一次有效伤害。
- [ ] 墙与关门等实体按最早接触阻断，箭寿命与跨前摇长帧推进不额外增加射程。
- [ ] 动作、握点、强化箭身、轨迹及反馈对应实际结果；墙体不显示虚假伤害。
- [ ] 暂停、失焦、画外和窗口变化取消未释放攻击且保持原冷却语义，已生效投射物按暂停规则处理。
- [ ] 通过玩家操作可演示多目标贯穿，并在已确认规则与输入边界补充回归，不改变普通箭。

验收追踪：AC-08、AC-12、AC-13、AC-20、AC-22。实现遵循父规格已确认的规则、输入适配和原生体验三个测试边界；本票涉及行为与画面一起验证。
