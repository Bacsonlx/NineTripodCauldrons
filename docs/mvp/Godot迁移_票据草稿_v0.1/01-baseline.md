## Parent

[Godot 迁移规格 #33](https://github.com/Bacsonlx/NineTripodCauldrons/issues/33)

## What to build

使后续迁移能够还原同一份旧版汤谷，并按已确认规则判断新旧差异；为 Windows 与 Mac 建立可追溯的测试设备登记。

## Acceptance criteria

- [ ] 固定当前代码和未提交改动、实际引用素材及数值的可还原参照，保留用户已有工作。
- [ ] 核对已观察到的 64 项外部行为用例，记录输入、时间推进、可观察结果和适用范围，列明已知缺陷与预期修正。
- [ ] 记录当前画面、操作和已有产物的参照版本，区分规则测试、构建、浏览器与原生实机证据；不补写历史通过。
- [ ] 登记指定 Windows x64 与 Apple Silicon Mac 的系统、CPU／GPU、内存及显示条件；尚未取得的数据明确待补，平台验收前必须补齐。
- [ ] 对照可重新构建或从完整归档还原，旧版主入口继续可用；本票不进行无关重构或长时采样。

验收追踪：AC-01、AC-26。实现遵循父规格已确认的规则、输入适配和原生体验三个测试边界；本票涉及行为与画面一起验证。
