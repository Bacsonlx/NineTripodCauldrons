## What to build

玩家能在影偶挥击与障碍附近使用空格闪避，看到方向正确的动作和残影，并按原有无敌窗规避或承受伤害。

## Acceptance criteria

- [ ] 移动时沿移动方向，静止时沿既有瞄准语义闪避，位移、无敌窗、冷却和打断规则保持。
- [ ] 闪避不穿过墙、关门或地图边界，跨闪避结束长帧保留普通移动余量。
- [ ] 敌人挥击与闪避无敌结束边界同步推进，不额外保护一帧或重复受伤。
- [ ] 暂停与操作中断取消残余位移而保留冷却，恢复后没有新输入不滑行；技能冲突按参照处理。
- [ ] 人物、墨影、扬尘与方向一致，本体可辨；规则及输入回归覆盖相关边界。

验收追踪：AC-10、AC-13、AC-20、AC-22。实现遵循父规格已确认的规则、输入适配和原生体验三个测试边界；本票涉及行为与画面一起验证。
