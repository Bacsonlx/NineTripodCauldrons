## What to build

玩家能够在真实 Godot 场景中短按或按住射箭，击中一个可受伤的影偶或被遮挡物拦截，并看到对应反馈。

## Acceptance criteria

- [ ] 短按完成一箭、按住连射、冷却内点击不排队，前摇／释放／恢复与参照一致。
- [ ] 箭从四向可见握点朝世界准星释放，复用上身、弓、箭的正确裁切与偏移。
- [ ] 按路径最早接触处理影偶与实体，沿用当前普通箭伤害和寿命，长帧不穿过遮挡或额外延长射程。
- [ ] 影偶生命、实际扣血、致死反馈和普通箭击退对应；墙体只产生碰撞反馈，击退不得穿墙或出界。
- [ ] 同一命中状态重复读取不重播效果；投射物和反馈结束可清理，并以规则输入／时间／状态边界测试。

验收追踪：AC-07、AC-08、AC-12、AC-13、AC-22。实现遵循父规格已确认的规则、输入适配和原生体验三个测试边界；本票涉及行为与画面一起验证。
