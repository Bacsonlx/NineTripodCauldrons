## Parent

[Godot 迁移规格 #33](https://github.com/Bacsonlx/NineTripodCauldrons/issues/33)

## What to build

用户能在 Godot 编辑器修改道路、障碍、敌人出生点和互动点，保存、重开、立即试玩以及导出包均体现修改，不需要改战斗源码。

## Acceptance criteria

- [ ] 提供可直接查看和调整的四类布局定义，脚点、可走范围与阻挡位置清楚，定义与生命／冷却／探索等运行状态分离。
- [ ] 道路与障碍修改同步改变实际通行与阻挡，出生点与互动点修改影响实际激活、追击和可达互动。
- [ ] 保存后重新打开、立即试玩及导出包均使用修改布局；不长期同步维护两份冲突布局真相。
- [ ] 用户按实际操作说明完成四类布局调整并验证效果，过程不需要修改战斗源码。
- [ ] 编辑验收使用可还原的布局变体，不把演示改动混入正式汤谷交付；正式地图布局与规则参照保持。
- [ ] 资产／布局非法引用或无效数据有明确检查结果；共享定义不会污染角色实例或重试状态。

验收追踪：AC-02、AC-23。实现遵循父规格已确认的规则、输入适配和原生体验三个测试边界；本票涉及行为与画面一起验证。
