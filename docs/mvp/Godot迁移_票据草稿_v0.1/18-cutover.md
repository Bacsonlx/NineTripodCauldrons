## Acceptance criteria

- [ ] 审阅 AC-01—AC-28 覆盖、自动化映射、小样与最终确认、两平台功能／性能／稳定性记录，失败或未测不得写成通过。
- [ ] 确认两平台证据对应同一正式内容和可追溯版本；平台修复引起共同内容变化时完成必要复验。
- [ ] 切换实际启动、构建与开发说明及项目规则到已验证Godot入口，核对新用户可按说明运行、测试、导出。
- [ ] 记录旧工具链决策的替代关系，保留二维平面、离线图集与跟随镜头规则；旧代码、资产、产物和对照证据可还原。

- [ ] 记录Steam早期兼容调查及其他后续范围，迁移完成不宣称手柄、正式存档、肉鸽闭环或商业发行已完成。
