## Parent

[Godot 迁移规格 #33](https://github.com/Bacsonlx/NineTripodCauldrons/issues/33)

## What to build

玩家在现有射箭场景中能够暂停、切出窗口、进出全屏、缩放和离开画面，恢复后瞄准正确且没有粘键或旧攻击补发。

## Acceptance criteria

- [ ] 按既有规则处理 Esc 暂停，失焦进入暂停并清理意图；恢复需要有效的新输入，不自行续射。
- [ ] 鼠标离开只取消待发攻击与对应意图，不清除仍合法的移动；返回时按住不续射。
- [ ] 缩放与全屏变化取消操作意图但不额外暂停；最大化、最小窗口、16:9 与超宽下人物不拉伸，世界瞄准转换一致。
- [ ] 快速按下松开、系统重复按键与渲染／规则帧错位不会丢点按或重复消费脉冲。
- [ ] 输入适配测试覆盖事件序列，原生键鼠和窗口操作保留真实复核证据，不能用伪造焦点代替。
- [ ] 中断路径可供后续技能和阅读统一使用；后续功能各自在该行为边界补充回归。

验收追踪：AC-07、AC-20、AC-21。实现遵循父规格已确认的规则、输入适配和原生体验三个测试边界；本票涉及行为与画面一起验证。
