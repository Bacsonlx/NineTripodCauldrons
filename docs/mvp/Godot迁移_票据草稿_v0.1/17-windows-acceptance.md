## What to build

在登记的 Windows x64 实机上实际运行最终候选包，完成完整汤谷键鼠体验、1080p 性能与稳定性验收。

## Acceptance criteria

- [ ] 绑定实际运行的产物、源码与资源校验，记录系统、CPU／GPU、内存、刷新率、缩放和实际输出条件。
- [ ] 通过真实键鼠完成战斗、探索、全部技能、R、阅读叠加失焦、缩放／全屏及睡眠恢复等功能复核；失败或未测分别记录。
- [ ] 预热后真实前台、1080p 连续跑射60秒，平均≥58 FPS、至少95%帧间隔≤20ms，保留全部逐帧数据和场景条件。
- [ ] 按明确计划做5分钟稳定性操作，检查无崩溃／卡死，记录投射物／反馈清理和内存趋势。
- [ ] 不丢慢帧、不关正常AI或效果、不伪造焦点；中止保留原因，不自行反复重启采样。
- [ ] 取得真实Windows结果并复核最终画面与手感；未取得回传保持待验，不以Mac结果、交叉构建或静态检查代替。
- [ ] 未达标先修复，影响共同内容的修改明确重验范围，本票通过只代表该Windows设备。

验收追踪：AC-03、AC-20、AC-21、AC-22、AC-24、AC-25。实现遵循父规格已确认的规则、输入适配和原生体验三个测试边界；本票涉及行为与画面一起验证。
