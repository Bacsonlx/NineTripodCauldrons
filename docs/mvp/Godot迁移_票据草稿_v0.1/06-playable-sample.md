## Parent

[Godot 迁移规格 #33](https://github.com/Bacsonlx/NineTripodCauldrons/issues/33)

## What to build

交付用户能实际试玩的正式迁移增量，完成角色移动、独立瞄准、普通射箭、一个影偶、一个遮挡物与跟随镜头，并记录用户确认。

## Acceptance criteria

- [ ] 小样使用已接入的正式规则、素材和表现，不另建抛弃式原型，包含单个影偶真实战斗与遮挡。
- [ ] 用户能够自然跑动、反向瞄准、射箭、受击、击败敌人及重试，暂停与窗口操作符合已接入规则。
- [ ] 提交可操作产物、版本／源码和资产标识、操作说明及必要截图／录屏，分开列平台已验与未验。
- [ ] 用户实际试玩并明确确认脚点、握点、动作、遮挡、镜头及整体画面／手感；记录对应小样版本。
- [ ] 小样存在问题先修复再确认，不能以静态图、自动测试或沉默代替批准；批准前不批量铺完整汤谷。

验收追踪：AC-04、AC-05、AC-22。实现遵循父规格已确认的规则、输入适配和原生体验三个测试边界；本票涉及行为与画面一起验证。

## Blocked by

- T04：完成单个影偶近战、玩家受击与死亡重试
- T05：跑通暂停、失焦、全屏与窗口变化后的安全操作
