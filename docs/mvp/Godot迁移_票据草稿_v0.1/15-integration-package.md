## What to build

从干净环境构建完整可玩汤谷，验证所有技能、遭遇、探索和编辑结果的整合行为，并交付可用于实机验收的同一版本双平台候选包。

## Acceptance criteria

- [ ] 冻结参照的全部适用行为用例已逐项映射并通过，报告长帧、操作中断、镜头、反馈去重与清理等差异和容差。
- [ ] 通过正常键鼠实际走完主路与两支路，使用全部技能、阅读、自然受伤后的祭坛、开门、完成后探索与R重试。
- [ ] 检查四向、上下身、握点、特效、HUD、地标及遮挡，表现改进有用户确认；小样通过不能替代全图复核。
- [ ] 干净导入、脚本／资源检查、行为测试与双平台导出有真实结果，失败可定位且不降低规格标准。
- [ ] 生成 Windows x64 与 macOS arm64 完整候选产物、版本／源码标识、哈希、资源清单与操作说明，原生包离线不依赖制作工具。
- [ ] 逐项整理 AC-01—AC-28 的已有证据和待验项，特别将本票构建／整合结果与后续原生功能／性能验收分开。
- [ ] 记录原生包的实际启动条件与未签名等分发限制，不在本票扩大到正式签名或商店发布。

验收追踪：AC-02、AC-03、AC-05、AC-06、AC-07、AC-08、AC-09、AC-10、AC-11、AC-12、AC-13、AC-14、AC-15、AC-16、AC-17、AC-18、AC-19、AC-20、AC-21、AC-22、AC-23、AC-26。实现遵循父规格已确认的规则、输入适配和原生体验三个测试边界；本票涉及行为与画面一起验证。
