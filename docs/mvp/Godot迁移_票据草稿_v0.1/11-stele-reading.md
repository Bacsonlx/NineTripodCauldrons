## What to build

玩家在完整战斗场景中安全靠近残碑后可按 F 阅读已批准正文，F 或 Esc 关闭并恢复操作，且阅读与失焦叠加不会绕过暂停或补发技能。

## Acceptance criteria

- [ ] 互动仅选择 80 世界单位内最近可达对象，不隔墙，提示与目标一致；短点按保留、长按及重复按键不重复触发。
- [ ] 已激活存活影偶、失败和普通暂停阻止新开互动且不积压意图，未激活影偶不阻止安全互动。
- [ ] 接入已批准正文，可关闭并重复阅读；阅读期间规则时间、已生效箭／箭雨和冷却冻结。
- [ ] 打开和关闭清理输入，取消待发攻击与残余闪避而保留冷却；覆盖普通箭、Q、E 与闪避，不补发或滑行。
- [ ] 阅读中 R 无效，阅读叠加失焦后关闭面板仍保留失焦暂停，按既有规则恢复。
- [ ] 安全范围、隔墙、多对象、快速点按、长按及阅读叠加中断通过外部行为回归和真实操作复核。

验收追踪：AC-15、AC-16、AC-19、AC-20。实现遵循父规格已确认的规则、输入适配和原生体验三个测试边界；本票涉及行为与画面一起验证。
