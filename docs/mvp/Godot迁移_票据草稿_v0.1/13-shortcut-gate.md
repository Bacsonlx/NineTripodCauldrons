## Parent

[Godot 迁移规格 #33](https://github.com/Bacsonlx/NineTripodCauldrons/issues/33)

## What to build

玩家能在祭坛支路内侧安全按 F 开门，过渡结束后通过捷径往返；外侧不能提前开门，关闭时可靠阻挡移动和攻击。

## Acceptance criteria

- [ ] 初始门关闭，从外侧不能提前开启，从内侧安全互动才生效，提示说明当前可用状态。
- [ ] 保持既有开启过渡，过渡中仍关闭，到期画面、移动、闪避和普通／穿透箭阻挡同步改变。
- [ ] 关门只在真实可见轮廓阻箭，空白区域不出现额外阻挡；长帧与击退不穿过关闭门。
- [ ] 打开后可双向往返，仍须完成剩余主路遭遇，三组完成后仍能开门，门直到重试前保持打开。
- [ ] R 复原关闭状态，规则与场景使用同一布局几何；通过真实路线和相应行为回归验证。

验收追踪：AC-08、AC-14、AC-15、AC-18、AC-19。实现遵循父规格已确认的规则、输入适配和原生体验三个测试边界；本票涉及行为与画面一起验证。
