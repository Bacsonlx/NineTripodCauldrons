# 0.2.1 补验说明

2026-10-17。游戏 EXE／ZIP 和运行资源均未改动；源码为 bea8534，产物哈希沿用发布清单。

Mac 原生全屏进入／退出及 1080p 输出 60 秒性能已通过。呈现帧平均 120.13 FPS，100% 间隔不超过 20 ms（内部画布 960×540，DPR 2）。本结果只对应这台 Apple M4／16 GB Mac。独立五分钟采样在 63.4 秒遇系统锁屏，按无效记录保留，仍待验。Windows 实机仍待用户回传。

采样工具修复了原始 trace 导出超时：Tracing／IO 使用浏览器级连接，并记录时钟锚点供呈现区间复核。旧 ZIP 附带的 capture-frame-timing.cjs 请替换成此次补充脚本；不用重新安装游戏。Node.js 22+，从最终包以 --remote-debugging-port=9335 启动后运行：

```sh
node capture-frame-timing.cjs --port 9335 --delay 10 --seconds 60 --out performance.json
node capture-frame-timing.cjs --port 9335 --delay 10 --seconds 300 --out stability.json
```

采样时保持游戏前台，实际跑动、射箭及使用技能。不要在采样中暂停、重试或切窗口。保持日常系统安全设置；发生锁屏、失焦或失败即保留无效记录，恢复后重新采满。回调指标须与实际呈现帧及战斗证据一起复核，不能单独宣称平台通过。

完整 60 秒呈现间隔、只读战斗输入摘要、锁屏时间、堆内存趋势与无效稳定性记录在 output/mvp02-validation/macos-foreground/。原始 compositor trace 以 gzip 无损归档于 out/validation/，归档哈希见 trace-archives-021.json。
