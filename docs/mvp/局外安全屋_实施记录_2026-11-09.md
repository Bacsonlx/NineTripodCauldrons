# 局外安全屋实施记录

2026-11-09，在主分支 `master` 按[正式需求](局外安全屋_需求与验收.md)直接接入运行场景。无参数启动按保存阶段恢复，否则进入祠庙前院。前院通过孩子、铁匠、商人和守祠人完成摆包、制作、购买、出征。地图地标与人物来自本轮[正式素材](../../assets/hub/shrine-v1/README.md)。

## 实施边界

- [安全屋场景](../../godot/scenes/safehouse.tscn)保留可编辑的通行轮廓、出生位置、NPC 与摄像机。孩子使用新四向无武器上身与已有四向待机、行走下肢。服务面板复用现有背包、祭坛、物品图标和嵌符规则。
- [玩家进度](../../godot/scripts/hub/profile.gd)保存一个本地进度。使用带版本的 Godot Variant 二进制保存类型化坐标和规则值，主文件通过同目录临时文件替换，读取失败时尝试最近可读备份。出征把扣款和本局检查点一并写入，结算把余额、香火、配方、残影和局内状态清理一并写入。
- [征程呈现](../../godot/scripts/presentation/room_journey_scene.gd)在清房、过门和索尔倒下时保存边界。索尔败退后继续走到出口，结算打开后再退出则直接恢复结算。主动放弃二次确认，不发放收益。开发命令独立加载测试内容，旧首页场景留作历史测试夹具。
- 操作说明见[试玩启动命令](../guides/试玩启动命令.md)。局外暂用“筹备资源”与三位 NPC 的职责名。香尽走已有结算类型，正式倒计时仍属后续。

## 2026-11-09 · 安全屋窗口布局修复
