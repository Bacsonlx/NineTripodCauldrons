# 地形与碰撞整改实施记录（2026-11-17 / 2026-11-18）

## 1. 背景与根因

针对 16 房互通地图在跑动、闪避、战斗走位与拐角处出现的频繁卡地形问题，经源码与场景几何扫描，定位以下核心根因：
1. **轴分离移动无切线滑动**：`training_room.gd` 原先仅做 X/Y 分离轴判定，单轴移动撞上斜向多边形边界时无法沿切线分流；且旧迁移参照依赖双精度标量累加，直接改用 `Vector2` 返回会产生单精度浮点往返误差。
2. **直角 AABB 与 5 点采样**：房间内部障碍采用生硬直角包围盒，`walkablePolygons` 仅做 5 点十字采样；`pull_player_toward` 仅检查终点可走，存在隔薄墙穿透风险；贴墙闪避未检查前方净空导致白扣精力。
3. **视觉路面外扩导致“空气墙”错觉**：`terrain_surface.gd` 默认向 `Walkable/Floor` 外侧绘制 `42px` 渐隐路面，叠加 `12px` 角色脚点半径后，可见路面比实际可站区域外扩过多。
4. **部分房间尖锐 90° 内折角与通道卡点**：`entry`、`stele`、`stele_side`、`ash_cloister`、`end` 存在多处 90° 内折角，`entry` 的 `PathStone`、`ash_cloister` 的 `InnerCornerWall` 及 `root_fork`/`gate_forecourt` 部分障碍占地偏大或紧贴转角。

## 2. 分阶段整改内容

### P0：底层移动与碰撞解算升级
- **保留旧场景标量路径**：`godot/scripts/combat/training_room.gd` 仅在正式独立房间（`walkablePolygons` 且带 `roomId`）启用新移动与圆角解算，冻结迁移参照保留原双精度标量路径（55 场景 / 4250 快照 0 偏差）。
- **接触法线切线滑动**：新增 `contact_normal()` 与 `slide_step()`，根据实际多边形边或障碍 SDF 计算接触法线并投影切向位移；正面垂直撞墙时正常停住，斜向接触时沿切线顺滑移动。
- **8 点脚点圆周采样与圆角障碍 SDF**：正式房间启用 `FOOT_OFFSETS_8`，障碍物使用带圆角半径的 SDF 判定，消除矩形四角钩挂。
- **连续路径防穿墙与资源保护**：`pull_player_toward()` 改为 4px 步进滑动（或 `clear_path` 校验），防止隔薄墙瞬移；正式房间贴墙正面按闪避/位移技能且完全无有效位移时，不扣除精力/蓝量与冷却。
- **安全屋同步滑动**：`godot/scripts/hub/safehouse.gd` 同步加入贴边滑动补偿。

### P1：视觉边界与物理边界对齐
- **`godot/scripts/world/terrain_surface.gd`**：对正式独立房间（`room_id != null`）将路面外扩过渡宽度收敛至 `10px`，并在边界处叠加柔和暗色岸线/苔土边缘（`draw_polygon`），使玩家看到的路面边缘与实际可站立边界对齐；旧连续地图 `tanggu_first_level_map.tscn` 保持 `42px` 原行为不变。

### P2 & P3：16 房重点修缮与轮廓自然化
- **`godot/scenes/rooms/entry.tscn`**：平滑 `RoomFloor` 与 `Walkable/Floor` 的 90° 阶梯折角，将堵塞左上内弯的 `PathStone` 外移至 `(365, 415)` 并改为无碰撞装饰。
- **`godot/scenes/rooms/stele.tscn`**：平滑 4 处内折角与外角，微调 `SilentStele3` 至 `(1065, 495)` 贴近外缘。
- **`godot/scenes/rooms/stele_side.tscn`**：平滑 4 处内折角与通道外角。
- **`godot/scenes/rooms/ash_cloister.tscn`**：将 L 形内拐角 `(710, 540)` 切角外扩为 `(625, 540) -> (710, 455)` 斜向转角，并同步将 `InnerCornerWall` 移至 `(645, 445)`、尺寸收为 `(115, 26)`，扩大高密度战斗转弯净空。
- **`godot/scenes/rooms/end.tscn`**：平滑 2 处 90° 内折角。
- **`godot/scenes/rooms/root_fork.tscn` & `godot/scenes/rooms/gate_forecourt.tscn`**：收敛 `LowForkRoot`（`220×50`）、`WestTraverse`（`135×34`）、`SouthTraverse`（`128×34`）占地，对齐美术底座并留出战斗走位净空。

### 专项回归测试
- 新增 `godot/tests/terrain_collision_checks.gd`（35 checks）并接入 `tools/migration/check_godot.py`，覆盖：斜边切向滑动、正面垂直撞墙停住、角落退出、牵引不穿薄墙、长短帧绕障一致性、贴墙闪避不误扣精力冷却，以及重点房间出生/门/互动可达性。
