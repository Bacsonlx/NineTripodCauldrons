# 商业深度肉鸽：人物连接与背面头部校准实施记录

日期：2026-10-30  
工程：`godot/`，Godot 4.7.2  
基线：`27736e9 feat: integrate current gameplay and content changes`  
当前状态：本轮修复与回归已完成，等待提交。

## 本轮目标

针对人物缩小到三分之二后出现的视觉问题进行深度修复，不以简单放大或添加无关内容掩盖问题：

1. **上下身断层连接修复**：解决人物在移动、待机、拉弓各状态下腰部脱节、悬空漂移的断层问题。
2. **背面头部比例校准**：校准背面转身状态下头部相对躯干与披风的过大比例，保持四向体量一致与边缘自然。
3. **坐标体系规范**：确立脚点为地面唯一世界基准，腰线为上下身连接基准，规则握点与箭矢弹道严格保持既有规则，不破坏战斗逻辑。

## 根因定位与技术决策

1. **断层脱节根因**：
   - 角色缩放为 2/3 后，原硬编码腰线偏移 `-30` 未统一换算为 `-30 * ACTOR_VISUAL_SCALE`（即 `-20`）。
   - 上一轮临时补丁在拉弓阶段（`draw`）尝试强行将上身位置与规则握点 `state.grip` 对齐（`align_muzzle`），但规则握点属于未缩放规则空间（如 Y=-92.88 或 -52.7），导致拉弓瞬间上身被水平扯开 15~72 像素、垂直扯开 10~30 像素，出现截图中上身悬空的严重断层。
   - `upperDown`（向下姿态）在拉弓时亦存在类似的绝对坐标覆盖，导致向下射箭时躯干被扯离腿部。

2. **架构解决方案**：
   - **清除临时位移补丁**：彻底移除 `align_muzzle` 与拉弓覆盖代码，上下身连接基准恢复为语义腰带下沿（腰线）。
   - **统一腰线坐标**：
     - `frame_actor` 处于世界坐标 `point + Vector2(0, bob)`，应用 `ACTOR_VISUAL_SCALE`（2/3）；
     - 内部 `upper` 和 `lower`（`hero-run-lower`）本地位置统一设为 `Vector2(0, -30)`，转换至世界坐标后精确位于 `point + Vector2(0, -20 + bob)`；
     - 外部 `torso` 定位在 `point + Vector2(0, -30 * ACTOR_VISUAL_SCALE + bob)`（即 `-20`）；
     - `legs` 落地在 `point + Vector2(0, bob)`，其裤腰顶端高度同样位于 `-20`。
     - 上下身在所有朝向（0/1/2/3）与动作阶段（待机、跑动、拉弓、释放、收势、技能、受击、暂停）的腰线世界距离保持为 0.0，且上衣下摆与裤腰自然重叠约 1 像素，消除所有空隙与重叠异常。
   - **规则坐标与战斗逻辑隔离**：
     - 脚点保持唯一地面实体基准，规则坐标、碰撞体、攻击范围、伤害与战斗时序完全不受视觉缩放影响；
     - 规则出箭点 `state.grip` 保持现有规则空间稳定性，箭矢生成位置与飞行轨迹未被篡改；视觉拉满帧箭尖随人物按 2/3 比例稳定呈现。

3. **背面头部校准方案**：
   - 测量确认：背面原图头部宽度约 47.5 单位，侧面头部约 34.5 单位，背面头部视觉占比过大；
   - 采用 Shader 遮罩分离头部与上身：
     - 底图通过 `head_repair.gdshader` 遮除头部矩形区域（保持身体、弓、肩膀、披风原始比例不变）；
     - 独立头部覆盖层 `head` 以 `0.86` 比例缩放，并以头部中心锚定，头发边缘与红领巾/披风保持自然过渡，无多余残影与缝隙；
     - 修复了此前 Shader 在 `mask_head == false` 时错误绘制全身底图的漏洞，修正为全纹理精确 UV 裁剪。
