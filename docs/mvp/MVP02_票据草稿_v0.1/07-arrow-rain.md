## What to build

玩家能用 E 在合法鼠标地面点落圈并分段攻击多个影偶；移动或转鼠标不改变已选落点，低矮掩体不阻断施法。

**规格覆盖：** AC-11、AC-12、AC-13、AC-16、AC-17。涉及跨票组合时，最终在 T12—T14 复验，不把部分覆盖记成整项通过。

沿用父规格的技术栈、二维等距世界、离线图集与公开行为测试入口；数值从父规格可调初值起步，记录实际值，不改变验收门槛。本票变更运行必要检查；涉及窗口、资源或构建时完成对应打包检查，并注明实际运行平台。

## Acceptance criteria

- [ ] E 新按下时从当前屏幕指针取得世界地面点，检查距离、地图和可站立范围；合法后固定落点，不追踪玩家或鼠标。
- [ ] 超距离、地图外和不可站立落点明确提示，不扣冷却，不静默改落点；不增加跨低矮障碍的射手视线限制。
- [ ] 先显示金色预告，前摇结束才开始伤害；按 Spec 的段数、间隔、半径和伤害初值结算，每段每敌最多一次，不按视觉箭支重复计伤。
- [ ] 预告阶段受击／闪避取消时清预告、不返还冷却；已开始落箭的区域继续，暂停冻结，R 全部清理。
- [ ] 接入共同动作互斥，Q／E 按住不连发、无效输入不缓存；正常移动不锁住；若 Q 已存在，同步回归互斥和打断。
- [ ] 提供可见范围、无效落点、分段落箭和冷却反馈，确认移动相机后仍落在所选地面点。
- [ ] 用公开行为和实际场景覆盖多敌、地图边缘、低矮掩体、预告取消和区域清理；正式动作及统一特效在 T09、T12 验收。
