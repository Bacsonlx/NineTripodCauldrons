## What to build

在大地图的一次占位遭遇中，玩家能射杀数只同款影偶，也会被可预判的近战攻击击伤、失败并按 R 重试。

**规格覆盖：** AC-08、AC-18、AC-20。涉及跨票组合时，最终在 T12—T14 复验，不把部分覆盖记成整项通过。

沿用父规格的技术栈、二维等距世界、离线图集与公开行为测试入口；数值从父规格可调初值起步，记录实际值，不改变验收门槛。本票变更运行必要检查；涉及窗口、资源或构建时完成对应打包检查，并注明实际运行平台。

## Acceptance criteria

- [ ] 提供至少两个可交互影偶供单体与后续贯穿／范围测试；本票完成一次基础遭遇，不提前替代三组正式编排。
- [ ] 影偶具有接近、预警、挥击、恢复和死亡，已激活后追击且能绕障，不能穿墙、离开通路或长期卡在直接路线的障碍后。
- [ ] 预警开始锁定朝向，挥击不追踪；身体接触不伤人，同次挥击不逐帧扣血；基础预警可见且与实际范围对应。
- [ ] 普通箭按轨迹首次接触，命中敌人一次后结束，墙柱仍阻挡；敌人生命与死亡可见，不因移出视野而重生或重复计数。
- [ ] 玩家生命、受击短硬直、短暂保护和基础血条可观察；受击取消未发普通箭，保护期不重复受伤。
- [ ] 生命归零冻结战斗并提示 R 重试；重置敌我生命、箭、效果、保护、输入及镜头，暂停仍沿用既有规则。
- [ ] 以 Spec 的生命、伤害、速度与攻击时长作为可调初值，补公开行为与真实场景验收；美术使用占位或动作小样，完整影偶由 T10 接入。
