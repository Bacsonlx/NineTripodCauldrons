## What to build

玩家能在约 2560×1440 的连续占位汤谷地图穿行，镜头跟随并在边缘停止，移动镜头后仍能准确瞄准和射箭。

**规格覆盖：** AC-02、AC-03、AC-04、AC-05。涉及跨票组合时，最终在 T12—T14 复验，不把部分覆盖记成整项通过。

沿用父规格的技术栈、二维等距世界、离线图集与公开行为测试入口；数值从父规格可调初值起步，记录实际值，不改变验收门槛。本票变更运行必要检查；涉及窗口、资源或构建时完成对应打包检查，并注明实际运行平台。

## Acceptance criteria

- [ ] 先以最小改动区分世界、视口和窗口，再接入约为旧世界宽高各两倍的可走空间及安全起点、残垣廊道、战斗庭院的占位布局。
- [ ] 保持等距角度、二维战斗、八方向屏幕移动、斜向归一和松键立即停止；边界与实体障碍阻挡、滑行和箭路仍正确。
- [ ] 镜头只跟随人物，不旋转、不按鼠标偏移；边界夹紧、不露空白；R 重试归位人物和镜头。
- [ ] 移动、握点、箭和碰撞使用世界坐标；HUD 使用屏幕空间；鼠标没有移动时，也随相机变化更新当前屏幕位置对应的世界瞄准点。
- [ ] 实际验证鼠标保持屏幕位置不动时移动／绕柱射击，以及近零瞄准、方向切换和贴障碍释放，准星、弓口与弹道一致。
- [ ] 公开行为测试和实际场景记录覆盖地图通路、镜头边缘与瞄准映射；记录坐标／视野约定，给后续敌人、技能和窗口适配使用。
