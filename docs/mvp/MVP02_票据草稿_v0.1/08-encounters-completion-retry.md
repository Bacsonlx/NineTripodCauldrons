## What to build

玩家沿连续路线依次激活并清除 2／3／4 只影偶，最后获得完成提示；失败或主动 R 可从地图起点重试整个切片。

**规格覆盖：** AC-19、AC-20、AC-21、AC-22。涉及跨票组合时，最终在 T12—T14 复验，不把部分覆盖记成整项通过。

沿用父规格的技术栈、二维等距世界、离线图集与公开行为测试入口；数值从父规格可调初值起步，记录实际值，不改变验收门槛。本票变更运行必要检查；涉及窗口、资源或构建时完成对应打包检查，并注明实际运行平台。

## Acceptance criteria

- [ ] 按路线进入区域激活三组固定遭遇，同组全灭后才可推进；未激活组不提前追击，不无限刷新、跳组或重复结算。
- [ ] 死亡而非暂时走远或不显示才推进计数；同一影偶只结算一次，出生与触发区位于可达通路。
- [ ] 提供当前遭遇及剩余数量的基础 HUD；最后一组清完提示完成，仍可自由走动和练习，不发奖励或写正式进度。
- [ ] 玩家生命归零优先失败，冻结战斗；与最后敌人同次推进死亡时不同时显示完成与失败。
- [ ] R 在运行、完成、失败可重试，主动暂停时无效，按住不重复；归位人物与镜头，重置所有当前已存在的练习状态。
- [ ] 以普通箭即可验证全流程；本票不等待 Q／E 或完整美术，后续技能必须各自接入既有暂停与重试。
- [ ] 保存一次真实通路与三组战斗／失败重试的记录，补公开行为测试；整合后的全部技能重置由 T12 复验。
