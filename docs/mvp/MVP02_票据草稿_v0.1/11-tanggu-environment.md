## Acceptance criteria

- [ ] 先接入并验证一段带树木与残墙的代表场景小样，统一视角、光源、色盘和轮廓，再扩充整张连续地图。
- [ ] 完成主地面／边界、残墙断口／石柱、日鸟祭坛、扶桑树／汤谷树根、远景／前景及少量细节动态，覆盖本票五组资产。
- [ ] 角色、敌人、实体物件、树冠／前景与 HUD 不烘入地面；交互障碍独立，分别记录通行区域、阻箭区域、排序脚点与遮挡层。
- [ ] 不套用其他地区树根，不新增祭坛交互；场景低噪声、装饰动态有限，边沿与路径清楚。
- [ ] 用实际三组遭遇检查出生、触发和通路可达，影偶可绕障，精修物件不能破坏已有路线或制造长期卡死。
- [ ] 绕树、残墙、柱和祭坛时排序、影子与必要淡化正确，人物不会持续完全消失；地图边缘及不同视野不露空白。
- [ ] 交付源图／可编辑源、分层与裁切描述、尺寸、区域与来源；保存实际探索战斗记录，后续技能与全场特效由 T12 复验。
