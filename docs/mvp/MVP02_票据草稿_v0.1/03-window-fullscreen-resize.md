## What to build

启动默认最大化，玩家能切换／退出全屏，在普通、4:3 与超宽窗口下看到不拉伸、铺满的游戏画面并正常操作。

**规格覆盖：** AC-03、AC-25。涉及跨票组合时，最终在 T12—T14 复验，不把部分覆盖记成整项通过。

沿用父规格的技术栈、二维等距世界、离线图集与公开行为测试入口；数值从父规格可调初值起步，记录实际值，不改变验收门槛。本票变更运行必要检查；涉及窗口、资源或构建时完成对应打包检查，并注明实际运行平台。

## Acceptance criteria

- [ ] 启动默认最大化，提供可辨认的全屏／退出全屏操作；桌面能力保持受限低频接口，不把逐帧战斗搬到主进程。
- [ ] Esc 保持暂停／恢复含义；全屏控件点击不同时触发射击或施法。
- [ ] 不强制 16:9 黑边，不拉伸人物；按比例调整可见世界范围，保持世界速度、射程、伤害与角色比例。
- [ ] 变化后同步相机边界、指针世界映射和 HUD；地图覆盖视野，不露出场景外空白。
- [ ] 全屏切换如引发失焦则暂停，回焦仍需手动恢复；清除无效输入，不自行续跑或补射。
- [ ] 验证 16:9、4:3、超宽与往返全屏的实际场景；检查并打包桌面资源，注明验证平台，Windows 实机结果在最终平台票补齐。
