## What to build

玩家能边移动边用 Q 贯穿同一路线的多个影偶，看到不同于普通箭的基础表现及冷却，障碍仍能挡箭。

**规格覆盖：** AC-09、AC-10、AC-16。涉及跨票组合时，最终在 T12—T14 复验，不把部分覆盖记成整项通过。

沿用父规格的技术栈、二维等距世界、离线图集与公开行为测试入口；数值从父规格可调初值起步，记录实际值，不改变验收门槛。本票变更运行必要检查；涉及窗口、资源或构建时完成对应打包检查，并注明实际运行平台。

## Acceptance criteria

- [ ] Q 新按下合法时开始短前摇与冷却，释放取当前瞄准，移动不中断；按住不连发，不做蓄力。
- [ ] 穿透多个敌人，每敌每箭至多一次；按运动轨迹顺序结算，只伤到墙、柱、实体障碍或边界阻挡之前的敌人。
- [ ] 普通箭仍为首次命中后结束；贴墙柱不能在障碍另一侧生成强箭，快速位移不越过薄目标。
- [ ] 接入 T05 动作边界，和当前可用攻击不同时起手，不缓存冷却或前摇内输入；闪避／受击取消未发箭且不返还已受理冷却。
- [ ] 已飞穿透箭不因普通受击消失；暂停冻结、画外取消未发箭、R 清理，存续结束及时销毁。
- [ ] 提供基础强化箭、动作区分、箭迹和冷却可见反馈；正式人物／武器及统一特效分别在 T09、T12 验收。
- [ ] 公开行为与真实输入验证多敌去重、障碍顺序、移动转向和取消；若 E 已存在，同步回归二者互斥。
