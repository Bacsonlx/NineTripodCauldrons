## What to build

玩家能用空格短闪避躲过影偶攻击，穿过敌人但被墙柱阻挡，并在清楚的攻击／受击规则下行动。

**规格覆盖：** AC-14、AC-15、AC-17。涉及跨票组合时，最终在 T12—T14 复验，不把部分覆盖记成整项通过。

沿用父规格的技术栈、二维等距世界、离线图集与公开行为测试入口；数值从父规格可调初值起步，记录实际值，不改变验收门槛。本票变更运行必要检查；涉及窗口、资源或构建时完成对应打包检查，并注明实际运行平台。

## Acceptance criteria

- [ ] 有移动输入按移动方向闪避，无移动输入按最后有效瞄准方向；距离、时长、无敌窗和冷却使用 Spec 初值并记录调校。
- [ ] 闪避沿途检查实体阻挡，不能穿薄墙柱，最终落点合法；允许穿过敌人。
- [ ] 无敌窗按规则时间判定，与透明度和显示帧无关；途中不能攻击，结束后恢复正常控制。
- [ ] 闪避可取消自身未释放普通攻击；受击硬直中不能攻击或启动闪避；受击保护与闪避无敌分别处理。
- [ ] 建立当前攻击／技能共同遵守的受理、取消与冷却边界；只实现眼下动作所需能力，不提前引入通用技能插件系统。
- [ ] 暂停、失焦、画外键盘输入与 R 重试正确处理闪避、冷却及无敌状态；冷却内按键不缓存。
- [ ] 提供可用的基础姿态／残影与冷却提示，在真实影偶挥击中演示窗口内免伤、窗口外受伤；最终动作和特效分别由 T09、T12精修。
