## What to build

玩家在既有房间中使用代表画风的完整MVP人物、弓和箭进行待机、跑动、瞄准、射箭与连射。动作沿T5样例确定的规格制作并接入，不改变已经确认的玩法，使占位操作成为可评审的角色动态体验。

沿用父Spec的TypeScript／Phaser WebGL／Electron／Forge基线；此MVP保持固定等距2.5D、单屏二维平面，不新增骨骼运行时或逐帧IPC。阶段A先用占位素材，阶段B才验证代表画风。所有结果须标明实际执行平台，未测试不得记通过。

覆盖父规格用户故事：2, 6, 7, 9, 10, 11, 13, 14, 15, 36, 37。覆盖验收：AC-02、AC-04、AC-05、AC-06、AC-07、AC-08、AC-09、AC-10、AC-12、AC-13、AC-14、AC-18；引用用例有拆分时以本票验收条目明确的部分为准。相关资产：MVP-A01、MVP-A02、MVP-A03、MVP-A04。

## Acceptance criteria

- [ ] 按已验证样例补齐待机、跑动、持弓、拉弦、放箭、收势及必要方向；具体帧数由样例确定，不增闪避、受伤死亡、附体剧情或其他完整角色。
- [ ] 透明帧／图集及裁切偏移、脚点、连接点、握点、释放点完整可用；保留源文件和说明；无重复弓或重复自带阴影。
- [ ] 弓与箭体现所选皮影／木刻方向；一款箭旋转复用，金色攻击可读，人物约80设计像素为调校起点。
- [ ] 跑动、原地瞄准、左右／上下反向跑射和斜向跑射无明显脱节、跳点或步态漂移；真实弹道不因美术方向数被限制。
- [ ] 动画播放与攻击事件分开，连射仍一周期一箭，普通松手与出画面取消行为正确；换素材后弓口不得穿障碍、命中位置不得错位。
- [ ] 对本票列出的AC用例做角色替换回归，保留短录屏和参数；不以静态立绘或占位版旧结果代替动态评审。
- [ ] 新资产进入两平台资源打包流程，类型与必要打包检查通过并说明实际执行平台；最终两端完整运行与性能由T8收口。
