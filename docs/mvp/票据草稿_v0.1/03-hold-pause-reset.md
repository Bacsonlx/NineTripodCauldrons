## What to build

玩家能持续跑射，普通松手结束后续连射；将鼠标移出画面、切走窗口或按Esc时，攻击按已确认规则中断。返回后不会自行续射，按R能清空并重复同一练习。所有操作在同一个房间端到端可验证。

沿用父Spec的TypeScript／Phaser WebGL／Electron／Forge基线；此MVP保持固定等距2.5D、单屏二维平面，不新增骨骼运行时或逐帧IPC。阶段A先用占位素材，阶段B才验证代表画风。所有结果须标明实际执行平台，未测试不得记通过。

覆盖父规格用户故事：10, 11, 12, 28, 29, 30, 31, 32, 33, 34。覆盖验收：AC-06、AC-13、AC-14、AC-16；引用用例有拆分时以本票验收条目明确的部分为准。相关资产：MVP-A02、MVP-A09、MVP-A11。

## Acceptance criteria

- [ ] 可攻击时短按一箭，按住按固定间隔开始后续攻击；普通松手让已起拉弦的一箭完成，间隔内短按不排队；每个攻击周期仍只一箭。
- [ ] 鼠标到黑边或离开有效画面时取消未发箭并清除连射；已飞出箭继续、键盘移动可继续。鼠标回来须重新按下，不沿用离开前或画外按住。
- [ ] Esc暂停／恢复；失焦自动暂停，回焦仍暂停直至Esc恢复。暂停停止人物、箭、效果与攻击间隔；未发箭取消、已飞出箭冻结，恢复后继续飞。
- [ ] 暂停、失焦后清空输入，恢复需重新输入；没有粘键、积压攻击或自行续射。暂停时R和攻击不生效，简短暂停文字可读。
- [ ] 运行中R一次归位玩家、恢复靶外观、清命中数／箭／效果／输入／未发箭，恢复可攻击与默认朝向；按住R不重复触发。
- [ ] 连续重置20次，柱和靶数量恒定，无旧箭、重复回调与输入残留；关闭重开仍为初始房间，不存练习进度。
- [ ] 操作提示包含短按／按住射箭、Esc与R；不扩大为完整菜单、存档或正式HUD。
- [ ] 实际完成AC-06的连射与出画面边界、AC-13、AC-14及AC-16重开部分；检查前摇、飞箭和跑动中的暂停，不只测静止状态。
