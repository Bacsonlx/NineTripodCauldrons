## What to build

将代表人物和汤谷环境组合为同一版本的可解压运行产物，在Apple Silicon Mac与Windows x64实机分别完成全部操作、美术、稳定性与性能验收。修复本闭环内的实际问题，提供可复核证据，形成MVP-01可交付版本；缺一端不算完成。

沿用父Spec的TypeScript／Phaser WebGL／Electron／Forge基线；此MVP保持固定等距2.5D、单屏二维平面，不新增骨骼运行时或逐帧IPC。阶段A先用占位素材，阶段B才验证代表画风。所有结果须标明实际执行平台，未测试不得记通过。

覆盖父规格用户故事：8, 28, 29, 32, 33, 35, 38, 39, 40, 41, 42。覆盖验收：AC-01、AC-02、AC-03、AC-04、AC-05、AC-06、AC-07、AC-08、AC-09、AC-10、AC-11、AC-12、AC-13、AC-14、AC-15、AC-16、AC-17、AC-18、AC-19；引用用例有拆分时以本票验收条目明确的部分为准。相关资产：MVP-A01、MVP-A02、MVP-A03、MVP-A04、MVP-A05、MVP-A06、MVP-A07、MVP-A08、MVP-A09、MVP-A10、MVP-A11。

## Acceptance criteria

- [ ] T6与T7已完成并集成，最终版本包含同一套场景、素材和玩法参数；范围仍是一房间、一玩家、三柱、两靶，不追加Boss、AI、剧情、存档或手柄。
- [ ] 分别提供Mac Apple Silicon与Windows x64 ZIP，各至少一台真实设备解压启动且离线加载资源，执行AC-01至AC-19；必须运行最终代表素材版本，不用开发服务或仅构建成功替代。
- [ ] 人物、弓箭、地面与石柱已代表选定风格；训练靶、基础反馈、影子、准星可保留程序表现，说明保留的占位项。功能与美术两阶段的两平台记录齐全。
- [ ] 两端1920×1080输出，允许1280×720内部画布等比输出；预热后前台连续跑射60秒，分别平均≥58 FPS，至少95%的有效呈现帧间隔≤20毫秒；不可平均两端结果或降低门槛。
- [ ] 加载、暂停和切窗单独验证；若打断采样，恢复稳定后重采完整60秒并留原因，不删除卡顿帧凑门槛，不用单段逻辑执行耗时代替呈现帧间隔。
- [ ] 两端另做5分钟操作，无崩溃、卡死、持续累积的箭或特效；记录对象清理和内存趋势，并验证连续重置20次后实例恒定。
- [ ] 保留每端应用版本／源码修订、ZIP名称、系统、架构、CPU／GPU、内存、刷新率与缩放、内部／输出尺寸、玩法参数、各用例结果、原始采样或可复核统计、截图／录屏。
- [ ] Windows测试设备的实际配置补录后真实执行；没有设备或证据时本票保持未完成，不虚构通过，不宣称全部Mac／Windows机型或正式战斗容量保证。
- [ ] 项目类型检查和必要构建打包检查完成，说明实际执行平台。对失败做闭环范围内修复后复验，不增加无关重构；本票不负责关闭或修改父Spec。
