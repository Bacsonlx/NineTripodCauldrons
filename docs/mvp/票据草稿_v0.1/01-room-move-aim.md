## Parent

Part of [Spec #1](https://github.com/Bacsonlx/NineTripodCauldrons/issues/1)。

## What to build

玩家从现有Electron／Phaser入口直接进入一个固定单屏汤谷占位庭院，使用WASD绕三个柱子跑动，鼠标准星和持弓方向独立转向。可看到两个静态靶及简短操作说明，为后续射击提供可操作场景。此票交付可演示的房间体验，不要求先建立独立引擎框架或正式美术。

沿用父Spec的TypeScript／Phaser WebGL／Electron／Forge基线；此MVP保持固定等距2.5D、单屏二维平面，不新增骨骼运行时或逐帧IPC。阶段A先用占位素材，阶段B才验证代表画风。所有结果须标明实际执行平台，未测试不得记通过。

覆盖父规格用户故事：1, 2, 3, 4, 5, 6, 7, 23, 25, 26, 34。覆盖验收：AC-01、AC-02、AC-03、AC-04、AC-09、AC-11；引用用例有拆分时以本票验收条目明确的部分为准。相关资产：MVP-A01、MVP-A02、MVP-A05、MVP-A06、MVP-A07、MVP-A08、MVP-A10、MVP-A11。

## Acceptance criteria

- [ ] 固定等距2.5D外观、二维平面、相机不滚动不旋转；一玩家、同款三柱、同款两靶，出生点不重叠，有连续绕行通路；一靶预留直射、另一靶预留柱后射线路径。
- [ ] WASD按屏幕方向跑动，松键停止，相反输入抵消；斜直各移动2秒的距离差以5%为初始容差；建议跑速220设计像素／秒，调参时记录实际值。
- [ ] 鼠标独立控制360°瞄准，初始朝右，近零距离沿用上次有效方向；准星与持弓朝向可观察，不以四向美术限制实际瞄准。
- [ ] 人物按脚点与柱基通行判定，被边界与柱基阻挡、可沿阻挡面滑行；头发、弓、红巾不扩碰撞；靶不挡玩家。
- [ ] 人物绕柱前后顺序正确，脚下影子贴地；被完全挡住时不持续原地跑步，不把柱头外框当柱基。
- [ ] 允许程序占位，人物能辨认待机／移动／瞄准状态；界面只展示当前可用操作，不新增正式HUD或菜单。
- [ ] 从房间实际输入验证本票覆盖的AC-01至AC-04、AC-09人物通行部分及AC-11，保留演示与有意义的行为检查；沿用1280×720设计画布和已有两平台打包配置，尚未实测的平台不记通过。
