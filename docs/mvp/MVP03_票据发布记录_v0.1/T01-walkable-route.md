## Parent

[MVP-03 Spec #17](https://github.com/Bacsonlx/NineTripodCauldrons/issues/17)

## What to build

玩家能在现有世界尺寸中沿真实道路完成三组战斗，走入两条支路并原路返回；提供全图通路布局与残碑短文审阅稿，先证明空间能走通。

基于已交付 0.2.1；固定等距二维平面、皮影为主及像素质感为辅。保留已有四种操作的战斗规则；不重新启动用户已叫停的反复长时采样。未获用户动态小样确认前，不批量铺满全图。

## Acceptance criteria

- [ ] 基于 0.2.1，世界仍为 2560×1440，保持人物大小、固定等距与跟随镜头；通路布局标明起点、三组庭院、两处岔口、残碑／祭坛点、捷径内外侧和主路地标。
- [ ] 灰盒中有明确的可走道路和围合，而非只在大矩形空地上画路；玩家能以正常移动到达主路三组及两支路物件前方。只做实现该通路所需的最小布局／碰撞调整，保留现有输入和战斗测试入口，不预建地图编辑器或通用框架。
- [ ] 三组按 3／4／5 原规则推进，不使用支路也能清敌完成；预留捷径从祭坛支路接回第三组前的主路，不绕过任何一组。栅门功能由后续票接入，本票不声称已能开门。
- [ ] 灰盒先用明确占位物件标示残碑、祭坛和关闭栅门；两支路均有正常入口可原路返回，不依赖尚未完成的开门能力才可探索。
- [ ] 提供初步当前区域／下一主路地标提示；镜头边缘和宽屏下通路仍可操作，无穿模、传送或无依据空气墙。
- [ ] 提交一段汤谷环境线索短文供用户单独审阅，记录候选版本及待审／已审状态；未审文字不当作正式内容，不阻止先验证灰盒和视觉小样。
- [ ] 通过现有房间输入推进验证主路和支路可达、边界阻挡、三组完成及 R 重试，并提供短程实际键鼠演示。灰盒通过不等于全图美术通过。

## Spec coverage

覆盖：AC-01、AC-02、AC-03、AC-04、AC-05、AC-07、AC-25。涉及多票时以最终整合／对应平台记录为准，单票不得把部分覆盖写成全项通过。

资产：本票不要求批量制作新美术；仅相应布局／交付记录。
