## What to build

玩家在同一最终候选版本跑完主路、可选探索和清敌回访，所有技能、交互、镜头和重试规则协同工作。

基于已交付 0.2.1；固定等距二维平面、皮影为主及像素质感为辅。保留已有四种操作的战斗规则；不重新启动用户已叫停的反复长时采样。未获用户动态小样确认前，不批量铺满全图。

## Acceptance criteria

- [ ] 使用正式环境及全部四种精修特效，从起点依次完成主路 3／4／5、读碑、回血、开门、回程与清敌后探索；同时验证忽略支路也可通关。
- [ ] 跨残碑、祭坛和门验证最近对象、距离／隔墙、安全限制、F 长按、阅读 F／Esc、阅读中 R、失焦保持暂停和输入清空，E 始终施放箭雨。
- [ ] 验证满血不消耗、40 点恢复封顶、已用不重复、门内外侧限制；R 一次重置新增探索状态与原生命／敌人／箭雨／特效／冷却／镜头，重启不保留探索。
- [ ] 回归普通箭／Q／E／闪避原伤害、冷却、判定及打断，复核效果结束、暂停、失败和 R 后无旧效果或额外命中；不关闭正常 AI 或效果证明通过。
- [ ] 覆盖全屏进出、普通／窄／宽窗口、镜头边缘和前景遮挡；人物、己方暖金和影偶朱红同屏可读，提示不离屏，主路与两支路辨识一致。
- [ ] 按父规格 AC-01—AC-29 整理已验证、待平台复测及未测状态，检查全部 A01—A14、碑文审批和小样确认记录；以现有行为入口和真实键鼠结果为准。
- [ ] 类型／静态检查和适用行为测试通过，提交问题修复与动态证据；不将本票复验当作 Windows 实机通过，不重新做反复长时采样。
