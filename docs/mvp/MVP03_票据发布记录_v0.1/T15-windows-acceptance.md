- [ ] 回传发现回归时修复并提供更新包，按实际受影响范围复验，记录版本关系；不擅自反复执行长时稳定性采样。
- [ ] 汇总两平台真实结果、剩余限制、素材／文案／小样批准记录；本票不修改或关闭父 Issue，也不关闭或补写旧规格的历史未验项目。
