## What to build

用户收到同一版 Windows x64 安装 EXE／ZIP 和 macOS arm64 ZIP；Mac 实际运行结果与 Windows 待回传步骤一并交付。

基于已交付 0.2.1；固定等距二维平面、皮影为主及像素质感为辅。保留已有四种操作的战斗规则；不重新启动用户已叫停的反复长时采样。未获用户动态小样确认前，不批量铺满全图。

## Acceptance criteria

- [ ] 构建同一版玩法和最终素材的 Windows x64 EXE／ZIP、macOS arm64 ZIP；记录版本、源码标识、文件名／哈希和资源清单，完整解压或安装后不缺离线资源。
- [ ] 在 Mac 实际包验证启动、主路／两支路、F 阅读／祭坛／门、四种特效、R、焦点与全屏，并保存实际截图／录屏和各项通过／失败／未测。不能以构建成功代替实际体验。
- [ ] 核对包装资源与已确认版本一致；提供键鼠操作、已知限制、未完成项及 Windows 安装／ZIP 启动与回传清单。不得把旧 0.2.1 包当作本轮新内容交付。
- [ ] 按改动运行必要检查与打包验证，不引入签名／商店／自动更新范围，不自行开启反复 60 秒或 5 分钟采样。
- [ ] Windows 仅可标记构建／包静态检查结果，其安装、实际功能和画面仍待用户回传；旧 MVP-01／02 未验状态不追溯改写。
