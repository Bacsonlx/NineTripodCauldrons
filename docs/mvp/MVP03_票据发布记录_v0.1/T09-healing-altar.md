## What to build

玩家安全进入第二条支路后主动使用祭坛恢复生命，能从反馈与熄灭状态辨认本次是否已用。

基于已交付 0.2.1；固定等距二维平面、皮影为主及像素质感为辅。保留已有四种操作的战斗规则；不重新启动用户已叫停的反复长时采样。未获用户动态小样确认前，不批量铺满全图。

## Acceptance criteria

- [ ] 在第二组战斗后的已规划支路接入祭坛，复用已完成的 F 距离、最近对象、不可隔墙、单次触发和安全限制。路过不自动使用，E 仍是箭雨。
- [ ] 每次从起点重试后的流程仅可成功使用一次，恢复 40 点、最多到 100；实际验证 30→70 和 80→100。
- [ ] 满血提示“无需恢复”且不消耗机会；战斗／失败／暂停／失焦或不合法位置也不消耗，之后合法时仍可使用。
- [ ] 成功恢复有短暂反馈并熄灭，已用再次按 F 不再回血；不会形成持续回血区或携带物品，特效不遮挡角色。
- [ ] R 重试后恢复可用且生命／战斗状态按基线重置，重启应用无上次使用状态，清敌完成后仍可用尚未使用的祭坛。
- [ ] 以真实受伤和清敌流程做短程演示，自动化断言外部生命／可用结果；记录 A09 可用、满血、成功和已用状态。
