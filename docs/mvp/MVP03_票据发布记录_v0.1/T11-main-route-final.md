## What to build

玩家能在统一风格的完整主路上看懂方向，依次作战并到达清敌终点，HUD 地标与实际景物对应。

基于已交付 0.2.1；固定等距二维平面、皮影为主及像素质感为辅。保留已有四种操作的战斗规则；不重新启动用户已叫停的反复长时采样。未获用户动态小样确认前，不批量铺满全图。

## Acceptance criteria

- [ ] 在通过用户确认的小样风格上完成起点、主路转折、两处岔口连接、三组庭院与终点的正式环境，不改世界尺寸和人物大小。
- [ ] 完成主路需要的 A01—A07 地面、铺装、边界、墙根石阶、树灌远景、灯火和地标；可复用现有素材，但整体不能退回仅更换单底图。
- [ ] 沿连续石铺／灯火／开口可辨认主路；当前区域和下一处主路地标随遭遇进度正确更新，不把探索当成必做，不增常驻箭头或小地图。
- [ ] 不使用支路仍能依次清完 3／4／5，清完显示完成且可继续走动；实体与地面通路匹配，遮挡、相机边缘、比例和世界瞄准正确。
- [ ] 两条支路入口和捷径连接遵循已规划布局，不能为了主路构图堵掉后续支路；全图支路环境由对应票补齐，本票不宣称其已最终通过。
- [ ] 复验受本票影响的实际通路、镜头、HUD 与战斗，提交主路动态和关键构图证据及素材来源。
