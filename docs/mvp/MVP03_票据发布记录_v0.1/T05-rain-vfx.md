## Parent

[MVP-03 Spec #17](https://github.com/Bacsonlx/NineTripodCauldrons/issues/17)

## What to build

玩家按 E 选定合法地面点后，能清楚辨认固定预告范围、分段落箭、落地冲击及消散。

基于已交付 0.2.1；固定等距二维平面、皮影为主及像素质感为辅。保留已有四种操作的战斗规则；不重新启动用户已叫停的反复长时采样。未获用户动态小样确认前，不批量铺满全图。

## Acceptance criteria

- [ ] 可在现有 0.2.1 地图从真实 E 输入演示预告→分段落箭→落地冲击→收尾，而非静态圆环。
- [ ] 保留原合法落点、施法距离、固定范围、预告时长、伤害段／时机和冷却；地图外、不可站立或超距离落点仍不扣冷却。
- [ ] 装饰光晕与落箭不误导有效伤害半径，移动人物／鼠标不拖走已确定落点，所有效果随世界与镜头一致。
- [ ] 己方暖金、影偶朱红预警和人物同时可读，不用不透明大面覆盖庭院；落地冲击不新增伤害段或击退。
- [ ] 暂停、失焦、未释放打断、已生效技能、失败和 R 遵循原边界，不重复落伤害或遗留技能区域。
- [ ] 保留落点和分段伤害回归，提交真实同屏动态证据及 A13 来源／状态说明，不自行进行长时采样。
