## Parent

[MVP-03 Spec #17](https://github.com/Bacsonlx/NineTripodCauldrons/issues/17)

## What to build

用户能在同一可操作版本中体验精修岔口、典型战斗区及四种操作，确认视觉方向后再开展全图制作。

基于已交付 0.2.1；固定等距二维平面、皮影为主及像素质感为辅。保留已有四种操作的战斗规则；不重新启动用户已叫停的反复长时采样。未获用户动态小样确认前，不批量铺满全图。

## Acceptance criteria

- [ ] 把岔口环境、现有人物／影偶和四种特效整合在同一真实游戏版本，实际走动、跟随瞄准并作战；不以四份孤立演示代替同屏效果。
- [ ] 提交可操作小样、对应版本／源码标识、截图／录屏，展示道路辨识、皮影／像素质感、普通箭／Q／E／闪避节奏和遮挡。
- [ ] 己方暖金和敌方朱红预警同屏仍可辨，镜头、输入及原战斗规则未被关闭或改写来制造效果。
- [ ] 记录用户对上述四项画面目标的明确确认及对应版本；未回复、存在未解决修改意见或静态图通过均不能将本票记为确认完成。
- [ ] 本票是全图正式美术制作的真实阻塞点；不因可生成素材就跳过。碑文审阅另行记录，画面确认不自动批准候选短文。
- [ ] 整合检查及必要短程操作有记录，不重新进行反复 60 秒／5 分钟采样。
