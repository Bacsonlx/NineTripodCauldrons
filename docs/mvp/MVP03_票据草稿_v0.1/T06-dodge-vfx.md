# [MVP-03 T06] 精修闪避墨影残像、扬尘与消散

## Parent

## What to build

玩家按空格时能从墨影和脚下扬尘看清位移方向，且始终辨认本体和敌方威胁。

基于已交付 0.2.1；固定等距二维平面、皮影为主及像素质感为辅。保留已有四种操作的战斗规则；不重新启动用户已叫停的反复长时采样。未获 T07 用户动态确认前，不批量铺满全图。

## Acceptance criteria

- [ ] 可在现有 0.2.1 地图演示移动方向闪避及静止按瞄准方向闪避，残像与扬尘有清楚的快速消散。
- [ ] 原距离、时长、无敌窗、独立冷却、打断与途中不能攻击规则不变，仍穿敌不穿墙柱。
- [ ] 残像为纯表现，不延长无敌或制造额外角色／碰撞／伤害；扬尘留在实际脚点，撞阻挡后不展示穿墙位移。
- [ ] 本体、脚点、影偶和朱红预警可辨，风格保持皮影与像素质感，不将残像误认为人物实际位置。
- [ ] 暂停、失焦、失败、R 与效果结束时正确冻结或清理，不留常驻影子或输入残留。
- [ ] 保留闪避及打断行为回归，提交同屏动态证据与 A14 来源／状态说明，不自行进行长时采样。
