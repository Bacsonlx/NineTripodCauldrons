## What to build

玩家用现有普通箭短按或按住射击时，能看见弓弦亮点、释放反馈、短箭迹与命中碎屑，射击节奏和结果保持不变。

基于已交付 0.2.1；固定等距二维平面、皮影为主及像素质感为辅。保留已有四种操作的战斗规则；不重新启动用户已叫停的反复长时采样。未获 T07 用户动态确认前，不批量铺满全图。

## Acceptance criteria

- [ ] 可直接在现有 0.2.1 地图完成，从真实普通箭输入到起手、释放、飞行、敌人／实体命中和消散形成完整可演示环节。
- [ ] 以暖金、皮影与像素质感精修亮点、箭迹和碎屑，不重画现有角色身份，不新增伤害、击退或持续效果。
- [ ] 伤害、射速、拉弦／释放周期、短按／连射、首次接触停止及与技能互斥等原规则不变；装饰效果不能越过已阻挡位置继续暗示攻击。
- [ ] 与影偶及朱红预警同屏时保持人物、脚点、危险范围可辨；特效世界位置随镜头正确换算。
- [ ] 暂停／失焦、打断、失败、R 与效果自然结束时正确冻结、取消或清理，不重复命中或留下旧箭迹。
- [ ] 保留相关房间行为回归，提交真实动态短片／截图及 A11 来源和状态说明；不编写只断言图片或粒子容器存在的测试，不自行进行长时采样。
