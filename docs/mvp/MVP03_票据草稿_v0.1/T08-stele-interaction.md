## What to build

玩家安全走入支路一，靠近残碑按 F 阅读，按 F／Esc 关闭并继续游戏；互动距离、遮挡与输入边界一起可验证。

基于已交付 0.2.1；固定等距二维平面、皮影为主及像素质感为辅。保留已有四种操作的战斗规则；不重新启动用户已叫停的反复长时采样。未获 T07 用户动态确认前，不批量铺满全图。

## Acceptance criteria

- [ ] 在已规划的第一组战斗后支路接入残碑和可读面板。沿用 T01 提交的短文审阅状态：已批准则使用批准版本；尚未批准可先明确展示占位文字验证阅读能力，不能将占位稿记作正式内容或进行未批准的碑文美术制作。
- [ ] 脚点到可到达的物件前方互动点约 80 世界单位为初值，仅提示最近合法对象；不能隔墙，同距顺序稳定，按下沿触发，长按不重复，提示目标与 F 结果一致。
- [ ] 有已激活且存活影偶、失败、普通暂停或失焦时不能新开互动，给简洁原因，不冻结战斗；未激活影偶不阻止安全探索。
- [ ] 阅读时冻结人物、箭、已生效技能和冷却；F／Esc 作为阅读关闭操作可在阅读暂停中使用，不同时射箭、施技、移动或立即重开；已读仍可再读。
- [ ] 关闭阅读清空输入，正常阅读暂停可恢复；阅读期间 R 不重试。阅读时失焦，回焦仍暂停，关闭面板不绕过失焦暂停，之后须 Esc 手动恢复。
- [ ] R 重置阅读记录，重新启动不保留；不接正式档案收藏、主线或持久化。将安全、距离／遮挡、单次触发和暂停处理随这条可演示互动完成，供后续祭坛和门复用，不另建通用框架。
- [ ] 通过房间输入／时间和可观察状态验证上述边界，并实测 F／Esc／E、不粘键与窗口边缘提示；记录 A08 素材／文案来源及审阅状态。
