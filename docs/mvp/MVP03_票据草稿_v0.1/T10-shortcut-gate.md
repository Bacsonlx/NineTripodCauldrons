## What to build

玩家从祭坛支路内侧安全按 F 打开栅门，画面、实际通行和箭的阻挡同步改变，形成返回主路的回环。

基于已交付 0.2.1；固定等距二维平面、皮影为主及像素质感为辅。保留已有四种操作的战斗规则；不重新启动用户已叫停的反复长时采样。未获 T07 用户动态确认前，不批量铺满全图。

## Acceptance criteria

- [ ] 在已规划的支路内外侧接入关闭栅门，只能从内侧安全按 F 开启；外侧、隔墙、远处、战斗、失败、暂停或失焦不能提前开门。复用已有 F 边界而不另造输入系统。
- [ ] 关闭时玩家／闪避不能穿过，按实体规则阻箭；打开后通行与阻箭同步更新，适用的敌人寻路遵循当前阻挡，无开门空气墙或关门穿模。
- [ ] 交付关闭、开启过渡、保持打开和提示状态；打开后可往返，当前流程不反复关门，重复 F 不产生多次开启或错误状态。
- [ ] 捷径接回第三组之前的主路；仍必须完成三组 3／4／5，不通过开门触发胜利，也不使不走支路的主路不可达。
- [ ] R 让门重新关闭并归位当前流程状态；重新启动不保留。清敌完成后仍能从内侧开尚未开的门。
- [ ] 自动化通过实际移动、射箭、闪避及重试验证开关前后外部结果，并提供内外侧实际操作；记录 A10 视觉与碰撞同步证据。
