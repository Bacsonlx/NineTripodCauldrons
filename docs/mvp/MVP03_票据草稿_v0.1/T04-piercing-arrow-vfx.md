## Parent

[MVP-03 Spec #17](https://github.com/Bacsonlx/NineTripodCauldrons/issues/17)

## What to build

玩家施放 Q 时能明确识别强箭起手和贯穿敌人的轨迹，撞实体时画面与伤害同时停止。

基于已交付 0.2.1；固定等距二维平面、皮影为主及像素质感为辅。保留已有四种操作的战斗规则；不重新启动用户已叫停的反复长时采样。未获 T07 用户动态确认前，不批量铺满全图。

## Acceptance criteria

- [ ] 可在现有 0.2.1 地图独立演示 Q 起手聚光、强化箭身、贯穿拖尾、各次有效命中及收尾。
- [ ] 暖金表现明显区别于普通箭，同时保留人物、敌人轮廓和朱红预警；沿实际瞄准及弹道绘制，不以身体四向限制真实箭角度。
- [ ] 原 Q 冷却、伤害、前摇、每箭对同一敌人仅命中一次、穿敌不穿实体和打断规则不变；拖尾与聚光不额外造成伤害。
- [ ] 用同线多个影偶及实体阻挡演示，障碍后的画面不能暗示箭仍在贯穿攻击；未来关门沿用相同实体边界。
- [ ] 暂停、失焦、前摇取消、失败和 R 不留下聚光或拖尾，不造成重复命中或冷却返还。
- [ ] 保留 Q 行为回归，提交动态证据及 A12 来源／状态说明，不以素材存在代替效果验证，不自行进行长时采样。
