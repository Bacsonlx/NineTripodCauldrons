## 1. 时间目标与变化来源

Q1：正常首通有效冒险时间15–20分钟，包含索尔战。暂停、失焦、读碑、营地整理、加载不计入有效冒险，现实总耗时另记；熟练速通可更快。本批不新增20分钟强制失败。

Q2：第一版采用13个主线房间和3个可选支路房间，全部双向连接。主线有清楚的深入方向，支路形成短环路并汇回主线，不跳过主线战斗房。

Q3：沿用鸟面近战、纸面远程、木甲厚血及现有任务机制，通过通路轮廓、视野、障碍、地标和敌人组合形成差异；本批不新增机关、护送或环境危险。

主线从谷口、日鸟石庭，经落叶溪床、幽根、碑林、扶桑残庭和中段祭火，深入灰烬回廊、残门前庭、赤日祭庭、雷庭前径，再到索尔和出口。采用现有独立房间场景方案，保留同一二维战斗平面及用户编辑成果。

## 2. 路线、成长与整理

主线顺序：

```text
汤谷入口 → 日鸟石庭 → 落叶溪床 → 幽根岔径 → 碑林遗径
→ 扶桑残庭 → 祭火营地 → 灰烬回廊 → 残门前庭 → 赤日祭庭
→ 雷庭前径 → 索尔雷庭 → 汤谷出口
```

Q4、Q6：普通构筑符按整个深入过程分布，整关最多8枚为可调初值。七个主线战斗房在首波首杀各掉1枚，A支路在末波首杀额外掉1枚；主线可发7枚，含A最多8枚。羊角／鼠毫按实际发放次数交替，真实击杀掉落、地面归属和往返去重保留，不把已发放等同于已拾取。Boss援军不发普通构筑符。

| 支路 | 两端主线房 | 收益与任务 |
| --- | --- | --- |
| A 苔石侧谷 | 落叶溪床、幽根岔径 | 可选短战斗，末波首杀额外1枚构筑符 |
| B 残碑幽径 | 碑林遗径、扶桑残庭 | 可选故事线索，阅读并合上残碑后开门 |
| C 余火侧林 | 灰烬回廊、残门前庭 | 可选战斗，清场后可使用一次回血祭火 |

支路不独占主线通关必需的核心物品，不新增宝箱或商店。野怪药囊及Boss援军补给沿用现有规则；更多波次带来的资源变化须采样，不能静默改掉率或基础战斗数值。

Q7：精细整理仅设在入口、祭火营地、雷庭前径三处，取消三庭的整理入口。整理自选，暂停规则时间，不免费回血回蓝；一次性回血祭火独立处理。满血仍可通过安全房，进入Boss不自动补满资源。

## 3. 引导与短碑文

Q9：小地图保留整关轮廓、暗色未访问房间及访问状态；M继续查看当前房间全貌。场景通过日纹、扶桑根、雷光等地标指引深入。

Q11：门显示目的房名，主路补充“前行／返回”，支路入口标“可选支路”，支路出口标“汇入主路”。方向以入口至Boss的设计顺序为准，完成状态独立显示；不能因为房间曾访问就把门统一标成返回。保留双向探索，不新增自动路线规划、整关大地图界面或强制箭头。

Q12：主线碑林保留既有互动，B支路新增一则一至两段的短碑文，补充汤谷环境和已有线索，阅读并合上后开门。正式文本后续单独列稿审核，不新增关键真相定论或长段强制演出。灰盒占位明确标注，不把主线碑文重复使用作为正式交付。

## 4. 完整征程、快速测试与重试

Q5、Q10：首页区分完整征程与快速测试。关卡当前只有“第一关·汤谷”，测试可选其中任意已实现房间；不显示未实现地区。

快速测试新建默认构筑、生命／蓝量／精力各100的独立测试局，使用房间默认合法出生点并留出辨认场景的空间。入口按现规则先整理，其他房按正常任务触发；可继续推进或回溯，不伪造前序清场、奖励或构筑。测试完成不得计作正式完整通关，入口房测试同样保留测试身份。

首页仅选关卡／房间，不增加资源修改、模拟构筑或固定种子表单；已有CLI高级调试保留。

Q8、Q13：

| 操作 | 已确认行为 |
| --- | --- |
| 完整征程存活时R | 先确认，确认后从入口新局重来，清空本局临时进度 |
| 阵亡后R | 直接按本次起点与初始条件新局重试；完整征程起点为入口 |
| 快速测试R | 直接回本次所选起点与同一初始条件，新建测试局 |
| 暂停／阅读／整理中R | 无效，不借此绕过已有操作中断规则 |
| 暂停菜单返回首页 | 先确认，说明本次未保存进度将清空；确认后结束本次内存流程 |
| 确认层打开期间 | 暂停规则时间并清理持续输入，确认只执行一次 |
| 取消确认 | 保留进度、资源及打开前状态；从暂停菜单打开则仍暂停，不恢复已清理的持续输入 |

本批不新增保留构筑的单房复活或磁盘续局。既有“退出后从房间结算点续玩”的后续方向仍保留，当前丢失进度提示只描述本批实际能力。

## 5. 初值、施工与验收边界

以下为可调施工初值，不承诺玩家实测结果：

- 16房、18对双向连接、36门实例；新增8房，复用并按需修订原8房。

- 最多8枚构筑符及逐房波次、敌人组合按灰盒与完整试玩调校；修改时同步计划和证据，不把初值锁成最终平衡。
