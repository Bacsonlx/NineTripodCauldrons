## 1. 新版故事的关键变化

| 内容 | v1.2 的表述 | 对后续设计的影响 |
| --- | --- | --- |
| 玩家身份 | 玩家是封神榜最后一个空位，叙事以泗水捡到青铜碎片的孩子作为身体与情感锚点（第 3—6 页） | 玩家跨局身份、当前所请之神与叙事观看角度不能混成一个“角色”概念 |
| 请神深度 | 附体是一整局的操作体系；同行是短段落简化体验；借眼是不要求操作的短暂观看（第 5—6 页） | 三者不能都按完整可玩角色计算，也不能由同一个角色解锁条件一并控制 |
| 叙事可达 | 后羿可以走完全部关键剧情，其他神的完整操作体系是额外路径；借眼可跳过而不丢进度（第 5—6 页） | 关键证据和主线不应以玩家掌握另一套战斗操作为前提 |
| 四个位置 | 盘古为死者、夸父为阻止者、后羿为执行者、女娲为修补者（第 4—5、17—18 页） | 共用案件、地区与 Boss，通过不同所见补全信息；不等于要制作四套独立主线 |
| 香火与名字阶梯 | 香火作为局外累计数值，关联无名／有姓／一方／真名四档（第 9—10 页） | 与单局一炷香的剩余时间分开；统计、解锁和难度作用域尚须明确 |
| 镜像 | 同伤、共血、战后选择签署“自愿”或“他杀”，历史签署多数影响后续地图与词条（第 10—11 页） | 战斗共享状态、签署记录、地区表现版本和词条解锁之间产生新的依赖 |
| 北欧线 | 低档通过物、招式和空缺铺垫，真名档才亲自到场；低档叙事避免直接点名北欧阵营（第 11—12 页） | 需要按叙事阶段控制敌人外观、词条名称、音频与文字的揭示 |
| 奥丁 | 真正的抢位者，终章所求是玩家的证词；睁眼被解释为最终签署（第 16 页） | 终章需要汇总既有证据与签署，不适合只靠孤立的结局选项触发 |

## 2. 内容分期：文档目标与技术验证分开

PDF 的 v1.0 目标为：后羿一位完整附体角色，汤谷／归墟／幽都三个地区加泗水终章，7 个 Boss、鼎成／奔月两个结局，约 30 条动作改造型词条；档二、档三留到更新（第 12—13、16—19 页）。这是新版提供的内容范围，尚不等于已经拆解并估算完成的制作承诺。

已确认的近期工作目标仍是小范围战斗验证，不直接扩成上述完整 v1.0。盘古、女娲、夸父的完整操作体系后置；盘古永久删除地点等后期机制不再作为首个战斗切片的实现要求。

“一个动作骨架＋两套外观”可以减少镜像动画的重复制作，但双实体判定、共享血量、攻击编排、受击反馈和战后签署仍有实现与测试成本。“借眼成本约为零”也只能视为相对内容规模的表达；镜头、演出、跳过、暂停、证据发放和恢复仍需制作，不能按零工作量排期。

## 4. 架构需要补上的边界

以下为工程分析，不是已经拍板的数据结构或开发任务。

1. **身份与体验分开。** 区分玩家的跨局身份、当前附体之神、短暂借眼的叙事视角；观看其他神的证据不应误切战斗体系。
2. **物件与证据分开。** 九鼎碎片是被收集的故事物件；真相碎片是用于拼合事件的证据；世界内档案、签署记录与游戏存档也不能使用同一语义。
3. **时间与累计分开。** 单局剩余时间遵守暂停／中断恢复规则，跨局香火只在已定义的结算事件中增长；恢复同一局不应无意重复结算。
4. **世界变化要可重建。** 由签署历史得到地区版本，分别驱动名称、对白、场景表现与词条解锁。Q19 已确认地图变化从下一局生效，Q21 已确认地区独立统计、平票沿用当前版本；重复签署的提交约束与词条奖励时点仍需细化。
5. **镜像共血要有唯一结算。** 两条显示血条不代表两份独立生命与奖励；同次攻击能否同时命中两者、攻击是否同步、死亡与证据如何结算都需要明确。
6. **借眼纳入恢复。** 观看完成、跳过与中断后的证据发放必须一致，避免漏发或重复发放。强制对白已确认暂停香火，借眼／同行是否沿用这一规则仍待确认。

Electron、PC 单机离线、固定等距二维战斗、房间及战后检查点续玩与独立移动瞄准等决定保持有效。Q26 已确认 Phaser WebGL 等技术验证基线；本次故事更新没有提供必须换成三维引擎的要求。

## 5. 访谈承接

- 原待答 Q12（胜利结算）已由 Q20 的战后结算与检查点取代。
- 原待答 Q13（永久损失）主要涉及后置角色，保留为后续扩展边界。
- 原待答 Q14（鼎成重置范围）已由 Q27 确认：重置当前游戏进度，保留设置与独立结局记录，自动恢复不得撤销已完成的主动重置。
- 原待答 Q15（信徒变化与共用规格）的随机信徒前提已被 Q17 作废，不再继续要求按局随机更换信徒。
- 原待答 Q16（皮影＋像素质感的具体规范）已由 Q23 确认为皮影为主、像素质感为辅，不要求全画面严格像素网格。

Q17—Q28 已确认身体连续、香火与签署规则、混合画风、1080p／60 FPS 目标、图集动画交付、工具链与结局重置边界。本轮架构访谈已完成，当前基线见 [架构选型结论](九鼎_架构选型结论.md)。恢复细节、性能与素材产能进入验证，数值平衡与后置内容分阶段处理，不视为已经实现或通过。
