## 还原方法

使用 Python 3.12 或更新版本及 Git，在包含基础提交的本仓库内执行。目标必须尚不存在；恢复工具不修改现有目录或当前工作区。

```sh
python3 docs/migration/baseline-20261019/restore.py /private/tmp/九鼎-t01-restore
```

工具先校验恢复材料，再从固定提交导出指定范围、应用差异、解包新增文件，最后逐文件验证清单与字节哈希。任何不一致均报错退出，并保留新目标目录用于检查。恢复所需基础提交保留在仓库历史中，补丁与新增文件归档随本票提交保存。

恢复后的应用仍使用冻结的 npm 工具链：安装匹配 lockfile 的依赖后执行 `npm run check`、`npm test`，实际启动使用 `npm start`。本票验证时复用本机已有依赖以避免重新下载，依赖本身未收入归档；这证明源内容可还原及本机依赖下检查通过，不代表离线依赖安装或双平台原生构建通过。
