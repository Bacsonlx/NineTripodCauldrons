# 血瓶与蓝瓶：美术原型与接入计划 v0.1

2026-10-23。用户确认蓝瓶、血瓶掉落校验通过，要求先设计美术原型，再实现；查看三方向后选择 A「皮影药囊」。最终简化图已接入默认首关，验证见[制作与接入记录](../../assets/props/potion-pouches-v1/README.md)。玩法沿用已确认的[药瓶规则](../product/十日_玩法与运行规则.md#2026-10-22--野怪药瓶与-boss-掉落设计确认)，不修改数值、掉落、保底、F 拾取或奖励入库规则。

## 要回答的问题

血瓶、蓝瓶怎样既符合九鼎的皮影画风，又能在战斗地面上被快速辨认？比较器形与材质，不只比较红蓝配色。普通补给应与 Boss 装备／道具占位区分。

当前 `loot_view.gd` 用多边形瓶身及“血／蓝”文字作为灰盒。正式方向采用皮影为主、像素质感为辅，不强制像素网格，依据 [ADR-0001](../adr/0001-fixed-isometric-2d-world.md)、[架构结论](../architecture/九鼎_架构选型结论.md)及 [Sprite Forge 指南](Agent_Sprite_Forge使用指南.md)。资产库暂无专用战斗药瓶，不复用剧情药容器的身份。

## 原型参数与表现提案

- 瓶身高 28 世界单位，底部中心落地，阴影单独绘制。普通 720p 镜头约 28 屏幕像素、1080p 约 42；原型最初的 18 px 为压力检查。实现时核对 Boss 房 1440×1040、`fit_room(200)`，1280×720 的倍率为 0.5，瓶身约 14 px；最终源图预览补充 14 px 比例，不将算例当作原生画面已验收。
- 保留大面积朱砂红／靛蓝色、深外轮廓和少量浅色边。血瓶宽圆、蓝瓶棱肩或直筒；即使灰度下也应有区别。去掉瓶身上的“血／蓝”灰盒字，交互提示继续由 UI 绘制，不烘焙进图片。
- 闲置微浮动不超过 2 世界单位、约 2.7 秒一周期，阴影锚定地面；不开长光柱或大范围闪烁。目标瓶用淡金地环，靠近后显示 F 与资源用途。
- 资源已满时瓶身保持完整可见、留在地上，提示对应资源已满。成功拾取后用短暂上收／淡出表达补给，表现只能在规则确认成功后触发；暂停、失焦及重开遵循既有时间边界，不由动画驱动恢复。
- 原型支持尺寸、灰度、深浅色／棋盘格底、浮动开关及四种状态切换；F 仅触发视觉演示，不模拟战斗恢复。石地使用当前工程纹理，是比例示意，非运行截图或原生画面证据。

B 的一次透明边编辑未达目标，且改变主体比例，已另存为未采用版本。原型保留原 B 展示并明确标注暖雾问题，不能视为运行交付。A／C 仍有少量边缘半透明像素和不等高源构图；原型分别按主体区域等高显示，没有覆写源图片。最终素材应重新生成／编辑并检查透明边，而非把本页显示裁切直接当作正式图集合同。

素材工具检查报告含路径非 ASCII、未安装地图／代码绘图 Skill、可选 API／视频路线等警告；本次仅用内置静图工具，不需要这些路线，也不为消除警告扩大安装。当前无需声音、新视频或新骨骼运行时。
