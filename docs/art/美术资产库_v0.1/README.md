# 九鼎｜十日：美术资产库 v0.1

登记日期：2026-10-16。本轮只建立资产需求库，不绘制、不生成图片、不导入游戏、不改变已确认玩法。

这是一份基于现有材料的全量需求底表：包含首个验证切片、首版故事规划、后续章节，以及尚未采用的候选。**414 条管理记录不等于 414 张图片、414 个独立实体或已批准的制作量。** 每条可以是一件物体、一组模块、一套状态、一个展示视图或一个待定义的缺口。未知招式、奖励和关卡细节不能在当前阶段穷尽，已集中登记缺口。

## 登记原则

1. 玩家只有一个连续的孩子身体。后羿神相、镜中神相与后续附体表现关联主体，不生成每局不同年龄、性别的信徒角色库。
2. 人物“存在于故事”不等于必须有完整可玩动作、独立立绘或战斗Boss形态。盘古、女娲、夸父的首版叙事表现与后续附体体系分列。
3. 同一资产的完好、破损、发光、选中等列为状态；大量重复实例不逐个编号。九鼎各有身份，单独列九条；九个名字尚无个体设计，先作为群像／牌位组登记。
4. 镜像可以复用动作结构，但两套外观、特效、伤口和退场仍需分别检查。未确定配对的地方神不擅自补名。
5. 建筑、树、蛇身和场景前景允许在制作时拆层；当前按管理单元列出拆层需求，不把每层提前当成独立资产来膨胀数量。
6. 签署后的地区变化按覆盖件登记，复用同一个地点；不是为每种记忆重新绘制整套地图。
7. 不预设每位角色统一八方向、固定帧数或全套表情；不同角色按实际用途裁剪。所有尺寸、帧数、方向数、预算和制作工具仍待验证。
8. 所有新增小怪、未定武器、图鉴布局与界面载体都标明提案或占位，不能据此反推新的玩法。
