# 首关 HUD 原型对齐与资源启用

2026-10-21，用户对照原型与实际截图指出：大块黑色面板、过粗圆角条和偏大的姓名与原型不符。本轮以确认原型为依据修正原生UI绘制，不重画人物、地图或四个技能图标。

- 头像沿用v2身份与宋体，显示槽112×112；姓名由22缩至18逻辑像素，资源文字和数值14。
- 状态条统一高14逻辑像素，生命／蓝量／精力长度204／180／164；采用切角青铜细边、暗色槽底、单像素高光与端部小铆点。精力增加四分段刻度。
- 生命朱红`#C82D24`、蓝量矿青`#09A9BC`、精力草绿`#539C32`，字体继续暖白`#F2E6C5`，边框`#A58C60`。
- 移除整块圆角黑板，换为四条跟随文字行的低透明度墨色底衬；左下四动作位置和60像素图标保持。
- 技能下显示12／28蓝量与25精力费用；资源不足置暗，尝试触发时右下短提示；冷却遮罩与数字保持原有规则时间。

资源只在默认首关的七个独立房间启用，旧小样和冻结迁移参照维持历史行为。生命、蓝量、精力由规则快照驱动，HUD不裁决伤害、扣费、恢复或奖励。

规则：开局双资源100，Q12蓝／E28蓝，闪避25精力；击杀回4蓝、清波回12蓝、上限100；最后一次成功闪避后1.2秒开始每秒恢复10精力。前摇取消退蓝、冷却继续；生效后不退。跨房保留资源及恢复等待，R重置。完整规则、预算和边界见[能耗规格](../../../docs/product/首关_蓝量与精力规划_v0.1.md)。

头像／字体来源仍见[HUD v2素材说明](../hud-v2/README.md)。本轮没有新生成图像；切角条、墨色底衬及数值属于原生UI绘制，未将静态原型数值烘焙进图片。

验证包括40项资源规则、32项HUD状态与多尺寸布局、历史55场景／4250快照和真实输入七房通关。干净导入、导出包与前台待验状态见[本轮交付记录](../../../output/ui/hud-energy-20261021/README.md)。
