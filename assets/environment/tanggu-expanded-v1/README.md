## 参考与生成

`references/`保留本轮选用的无标注总览、四房近景、首页原型及路线数据，来源为此前本地ImageGen任务。参考图用于人工判读空间与风格，本次地表生成未实际附图；不把参考整图作为房间底图。

`dry-creek.png`与`ash-earth.png`由内置`image_gen`分别生成。前者为暖赭砂砾干溪，后者为低饱和灰褐灰土，均为1254×1254的完整地表材质原图；运行文件逐字节复制，未手工重绘。完整提示词见[prompts.json](prompts.json)，哈希和运行路径见[asset-record.json](asset-record.json)。生成要求为无地标、无文字、均匀光照、四边可重复的平铺材质；是否存在可见接缝仍以场景预览和原生画面核对。

AI选择理由：两图分别对应溪床与深入遗迹的色调，细小颗粒不遮挡敌人轮廓与预警；不包含会被误认成碰撞体的大物件。此为AI技术评审理由，不代表用户已确认新增材质的原生效果。

## 源文件、运行引用与验证

- 正式源文件为本目录两张PNG，运行副本位于`godot/assets/world/tanggu-expanded-v1/`，由普通Godot纹理导入。
- 房间仍使用独立环境实例、原生可走区和碰撞；材质只替换指定房间的地表纹理，不改变规则边界。
- 新房布局、实际运行引用和后台检查见[实施记录](../../../docs/mvp/汤谷首关扩展_实施记录_2026-10-26.md)。离线场景合成只是布局预览，不能作为Godot GPU截图或性能证据。
- B支路短碑文作为独立内容候选记录于实施记录，不用复制主线碑文充数；文本最终审核与原生视觉状态分别记录。
