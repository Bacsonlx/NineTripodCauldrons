# 汤谷低矮残石 · v1

2026-10-21，用于用户确认并要求实施的「扶桑残庭」v0.3 样板。替换样板 v0.2 中偏冷、尖耸的苔石，延续原石庭的灰褐石块、磨损纹样、暗苔与暖色落叶。

- `ruin_stone.png`：内置 imagegen 透明源图，1913×822，保留原始 RGBA。
- `prompt.txt`、`generation.json`：完整提示词、参考来源和 SHA-256；工具未返回具体模型与费用，不自行推断。
- 正式运行副本：`godot/assets/world/ruin_stone.png`；AtlasTexture：`ruin_stone.tres`，区域 `(133,220,1649,437)`。
- alpha>8 有效区为 `(141,228)—(1774,649)`；显示区向外留8像素。原图有 alpha≤8 的极淡外围像素，使用纹理区域取图，未修改 PNG 或透明度。

主残石脚点 `(750,630)`、显示宽170、实体150×40；四组边缘残石继续使用样板位置、显示宽和实体占地。显示宽170时主体约168×43。场景采用既有 `environment_prop.tscn`、深度排序和接地表现，没有接入原型专用的读图脚本。
