13组覆盖：四向待机下身、16相位跑动下身（四向身体×四向位移）、闪避下身；持弓待机／跑动、无弓待机／跑动上身；普攻、穿透箭、箭雨、受击、闪避上身；四向8帧倒地整身。移动与瞄准独立，按真实位移96世界单位取一轮步态；战斗阶段与发射仍由规则时钟裁决。T蓄势没有新增独立身体动作。

上下身按腰点完整XY连接，衣摆覆盖骨盆。鞋随腿烘焙，弓随手烘焙，挂件层不重复绘制这两个槽位；其余符印挂点读取当前动作帧。普通箭、技能箭的起点与肩高按新造型重新标定，近墙阻挡有四向回归。基础装备与伤害规则未变；本轮弓鞋仍采用统一基础造型，不宣称已制作全部装备外观变体。
