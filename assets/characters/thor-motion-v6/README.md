## 动作与限制

- 横锤：0.8 秒蓄力、0.12 秒生效、1 秒缓冲回位；身体先压膝和转髋，再带动胸肩、肘腕和锤。两脚承重，不用图片拉伸连接。
- 掷锤：1 秒蓄力，送肩出手、随挥、等待、迎接和0.8秒缓冲分开；飞锤地面距离仍来自规则。局部身体放大不放大地面飞行坐标。
- 落雷：压膝后举锤，空手护在胸前；三次引雷轻微缓冲后回位，完整4秒。伤害和落点由原规则裁决。
- 仅单方向现有素材，未补画四向、透视转身、手指握持新图或完整败退。骨架约束减少脱节／反折，不等于真实人体三维动作已解决；自然度等待用户动态判断。
