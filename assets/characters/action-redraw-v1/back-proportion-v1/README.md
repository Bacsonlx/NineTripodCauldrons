# CHR-001 背面上身比例校准 v1

2026-11-05，用户明确要求校准背面待机与行走上身。本版已接入；AI 评审与用户最终原生画面确认分别记录。

## 原因与实测

上一版只把背面行走对齐到背面待机，没有比较其他三向；背面上身本身偏小。按运行比例（含外层 `2/3`），冠顶到黑腰带下沿的高度如下，单位为世界单位：

| 对象 | 校准前 | 校准后 |
| --- | --- | --- |
| 正面 | 37.04 | 37.04 |
| 左面 | 36.45 | 36.45 |
| 右面 | 36.92 | 36.92 |
| 背面待机 | 约 22.16 | 37.36 |
| 背面行走 | 约 21.48 | 37.31 |

校准后冠顶到共享脚点：待机 56.56、行走 57.04，其他三向 56.45–57.04。旧版腰线采用人工标志点，校准版采用注册腰带点；数值是几何证据，不代替原生视觉认可。

构图采用上身联绘（手、弓、披带）与既有下肢离线组装，保留现有规则脚点、移动、碰撞和普通箭规则起点。旧弓／披带重叠区域按脚本中的 ownership 范围剔除，不能将结果描述成整张旧图像素均未改变。行走腰线额外重叠 12 个注册像素（0.96 世界单位），用于消除停步时上身高度突变。

上身同组不逐帧缩放；四阶段分别保留注册点与头部测量 ROI，排除举弓、箭尖对高度测量的干扰。行走八帧共用同一待机上身，避免头部、肩部的帧间变形；腿部相位照旧。

`tools/art/action_redraw/prepare.py` 从本版覆盖背面两套图集。复现命令（仓库根目录）：`tools/asset_forge/.venv/bin/python tools/art/action_redraw/register_back_proportions.py`。来源、输出 SHA-256、注册参数和 AI 决策见 [generation.json](generation.json)。生成模型名和费用未由工具返回，记录为未知。
