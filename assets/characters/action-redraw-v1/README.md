## 当前实际覆盖

- 主角：右向跑步、右向原地普通射箭、右向原地 Q／E、右向闪避；待机复用新普通射箭第0帧。普通箭前摇0.08秒、释放与收势仍取真实攻击状态和剩余冷却；Q／E、闪避使用规则剩余时长。
- 全身图中的弓、手臂跨腰线，不能简单横切为正式上下身。移动射击、未覆盖方向、移动技能及受击继续使用原分层；移动与鼠标瞄准仍独立。新帧生效时隐藏旧身体与武器，新闪避残影只复制新全身图，不叠旧上身。
- Boss：默认迈步与三招替换为新全身帧，仍为单方向；横锤前4帧覆盖0.8秒预警，第4索引帧覆盖0.12秒生效，后3帧覆盖1秒收招。投锤前3帧用于1秒预警，飞行使用真正空手的第4／5索引帧，接锤用第6／7索引帧；含锤离手图第3索引帧不叠加独立飞锤。引雷8帧采样原4秒时钟。
- 独立飞锤复用既有 hammer.tres，位置为规则地面点加固定空中高度；放大只作用视觉偏移与锤体，不放大地面路径。警告扇区、拖尾、电柱继续取真实规则。
- 步态取实际位移，重复快照不推进；主角暂停保留当前新姿态，重试／切房清空旧步态；主角失败和 Boss 静态败退沿用旧素材，新图没有死亡动作。呈现不裁决伤害，不等待动画完成。

## 视觉限制与待验

单方向新图不能代表四向或跑射组合已完成。原型已有左右腿支撑不足、头高／体量漂移、贴边裁切、弓弦与握点细节问题仍在；接入不补回缺失像素。新主角联绘箭尖尚未针对真实出箭点精修，斜向瞄准与招式危险方向也不由单向图精确表达。后台只能验证映射、资源、时间及中断；步态承重、脚滑、招式衔接、最终遮挡和玩家手感待原生前台评审，Windows 实测仍暂缓。
