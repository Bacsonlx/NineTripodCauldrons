## v1／v2覆盖（历史）

- 主角v2：向右移动使用新下肢，向右瞄准使用新射箭／Q／E上身，两者独立且支持移动射击。未覆盖的移动方向仅下肢回退，未覆盖的瞄准方向仅上身回退；原地用旧站立下肢。右向闪避仍使用上一轮完整帧。
- 全身图中的弓、手臂跨腰线，v2通过内置imagegen补出真正分离的上下身，未简单横切原图。新上身生效时隐藏旧上身与武器，新下肢生效时只隐藏旧腿；右向完整闪避覆盖两层，残影使用对应纹理、可见性及世界位置。普攻、Q／E、闪避均取真实规则阶段，步态取实际位移。
- Boss：默认迈步与三招替换为新全身帧，仍为单方向；横锤前4帧覆盖0.8秒预警，第4索引帧覆盖0.12秒生效，后3帧覆盖1秒收招。投锤前3帧用于1秒预警，飞行使用真正空手的第4／5索引帧，接锤用第6／7索引帧；含锤离手图第3索引帧不叠加独立飞锤。引雷8帧采样原4秒时钟。
- 独立飞锤复用既有 hammer.tres，位置为规则地面点加固定空中高度；放大只作用视觉偏移与锤体，不放大地面路径。警告扇区、拖尾、电柱继续取真实规则。
- 步态取实际位移，重复快照不推进；主角暂停保留当前新姿态，重试／切房清空旧步态；主角失败和 Boss 静态败退沿用旧素材，新图没有死亡动作。呈现不裁决伤害，不等待动画完成。

## 视觉限制与待验

单方向新图不能代表四向已完成。v2补齐独立跑射组合和逐帧腰点，但左右腿支撑不足、头高／体量漂移、贴边裁切、弓弦与握点细节仍需视觉确认。新主角联绘箭尖尚未针对真实出箭点精修，斜向瞄准与招式危险方向也不由单向图精确表达。后台只能验证映射、资源、时间及中断；步态承重、脚滑、招式衔接、最终遮挡和玩家手感待原生前台评审，Windows 实测仍暂缓。
