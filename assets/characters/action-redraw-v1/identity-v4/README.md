# 主角四向身份修复 v4

2026-10-27，用户以四张实测截图指出四向人物大小与形象不一致，并授权按“源图诊断、角色比例、最小必要修复、可复核证据”的要求修复。用户授权修复与接入；本批新图由 AI 选择工作版，尚未获用户原生动态认可。

## 依据与来源

身份参考为此前明确确认的[向下射箭原件](../../child/down-archery-v3.png)及其[接入记录](../../child/README.md)，没有把新右向候选当成新的角色标准。旧上身、技能、四向下肢和单向新帧分别作为姿态或衣物参考；实际附入生成的输入、提示词、PNG、SHA-256、工具路线和选择理由见[generation-calls.json](generation-calls.json)。使用内置 image_gen；底层模型和费用未返回，记录未知。未调用视频服务。

[原始诊断与标志点](../../../../output/art/CHR-001/2026-10-27-four-direction-v4/body-landmarks.json)区分造型、投影、身体比例、连接点、运行变换和武器。确认默认场景混用三代上身，新旧腰点定义也不同；上一轮单纯缩放和宽泛高度范围不能证明同一身份。

共47个修订姿态、9个运行图集。完整闪避新候选没有明显比例收益，未替换现有版本。Boss未修改。稀疏关键姿态仍是既有帧动画，不宣称是连续视频动画或已解决全部承重／步态问题。

[clips.json](clips.json)与[加工清单](provenance.json)记录逐帧语义腰点和每组固定等比缩放。新腰点统一为黑腰带下沿，接下肢切口，仍位于规则脚点上方30单位；不逐帧按alpha外框缩放，不强制四向武器／披风外框一样宽。背向head_rects仅供测试量头，排除弓箭，不参与运行变形。

[转换脚本](../../../../tools/art/action_redraw/prepare.py)先读v2几何／v3缩放，再用本目录覆盖同名主角图集并追加左／上和四向技能图集。运行[元数据](../../../../godot/assets/characters/action-redraw-v1/clips.json)和[来源清单](../provenance.json)对应当前文件，旧图、旧提示词和旧候选保留。

实际引用：[主角采样](../../../../godot/scripts/presentation/player_frame_actor.gd)、[训练／首关共用呈现](../../../../godot/scripts/presentation/training_scene.gd)、[换房注册](../../../../godot/scripts/presentation/room_journey_scene.gd)。移动方向选下肢，瞄准方向选上身。失败仍沿用原全身素材；暂停保留新层，重试／换房清理步态。

普通右／左／上箭尖分别标定为相对脚点 `(42.14,-52.704)`、`(-45.492,-55.704)`、`(-3.84,-92.88)`；向下继续 `(-0.12,-17.04)`。这是场景布局副本的发箭几何变更，实际箭从新位置发出，可能影响近墙射线；共享GRIPS常量、冻结规则夹具、技能握点、速度、伤害和时间均未改。实际单箭、箭尖衔接、肩部到出箭点阻挡及跨房流程已后台回归；斜向联绘弓与连续真实瞄准仍有原有离散朝向限制。
