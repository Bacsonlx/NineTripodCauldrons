改动针对用户反馈：站姿肩／腰／胯不再由alpha框中心拼合；腿宽适配新躯干，原地双腿自然下垂，未固定套用跑动的弯膝；持弓手和拉弦手使用不同手型，指腹覆盖弓握把；弓弦两端与箭尾取相同关节点。正／背弓保持竖直，用透视压缩宽度；背向遵循头／躯干遮挡，拉弦肘向外打开，箭朝斜背方向的上向扇区，仍是四向量化表现。

制作画布256×256、脚点(128,224)、腰点(128,174)，固定图集缩放0.75×演员2/3，约65世界单位中立身高。步幅由96改为48世界单位／循环，使50%支撑阶段的脚底后移匹配实际位移；膝踝与鞋底分开处理。动作阶段仍取既有规则，伤害、冷却、输入与移动速度没有改动。肩高由37标为36，普通／技能发射点重取本版拉满帧箭尖；近墙回归继续覆盖。飞行箭长与对应方向的搭弦箭一致。

覆盖四向：无弓／持弓待机与跑动、普攻、穿透箭、箭雨、受击、闪避、倒地；下肢支持四向身体×四向位移×16步态。G／C沿用闪避姿态，T无新增独立身体动作。弓与鞋不在挂件层重复显示，其他挂点取当前帧；没有制作全部装备造型变体。

这是一套绘制部件的离线关节动画，604不是独立手绘原画数量。姿态连接、四向矩阵及关键帧已由AI离线复核；头部遮挡、正背透视的可读性、连续自然度、最终过滤与手感仍须原生窗口确认。新帧未获用户视觉验收，不以后台断言替代。
