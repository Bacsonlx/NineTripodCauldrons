## 连接与瞄准

四格各 543×724，腰带基线 `[273,542]`，统一缩放 `0.12`；按正式规则的 `idle / draw / release / recover` 切帧，腰带仍连接在脚点上方 30 世界单位。此版上身联绘手／弓／弦及搭弦箭，显示时隐藏旧独立弓和搭弦箭，避免重复武器；其他姿态回到原分层。

移动方向选择下肢，鼠标方向选择上身，仍可反向跑射。上身是四向量化姿态，不对整张身体或联绘弓做任意角旋转；向下扇区内，飞行箭继续使用真实鼠标角度。连续细分方向的手部跟随仍需后续拆件／动作素材，不能以本次接入声称已有连续弓瞄准动画。

拉满帧箭尖为 `[272,650]`。旧 `grip` 接口承担发箭原点，新向下普通箭原点由 `(24,-48)` 标定为 `(-0.12,-17.04)`：`(箭尖-腰带)*0.12+(0,-30)`。运行场景复制布局握点后只修改 down 项，不污染共享常量或冻结规则夹具；技能继续使用独立 `SKILL_GRIPS`。这项几何标定会改变向下普通箭的初始射线，碰撞算法、肩部到出箭点阻挡检查、速度、伤害和攻击时钟保持原实现；需在真实画面复核近墙射箭。

向下普通飞行箭缩放为 `0.024`，与新搭弦箭约 35.52 世界单位的长度衔接；其余方向普通箭及穿透箭沿用原尺寸。飞行箭的位置与角度直接使用规则结果，没有显示偏移或伪造弹道。
