# 人物与弓箭精修 v2

本轮使用内置 imagegen 生成透明 PNG，原始输出已复制到本目录，未使用 Python 修改图片。参考图为 `output/九鼎_四组章节过程图_v1/01_汤谷_上香与镜像.png`，只用于统一人物设定与木刻材质。

## 交付与使用

- `child-refined-v2.png`：1254×1254，四方向×四种姿态（待机、左右跨步、拉弦），16 帧样例。`child-refined-v2.frames.json` 记录实际非等距裁切矩形和脚点；不能按规则网格直接切割。
- `bow-refined-v2.png`：1254×1254，向右瞄准的独立木弓，握点为原图 (805,620)。
- `arrow-refined-v2.png`：1536×1024，箭尖向右，箭尖参考 (1509,512)。
- 游戏内人物缩放 0.26，弓 0.035（拉弦时 0.037），箭 0.029；肩部参考点在脚点上方 52 设计像素。
- 四方向姿态配合连续旋转的弓与真实 360° 弹道；人物朝向带约 4.6° 滞回，防止分界抖动。跑动保留跨步，不用站姿拉弦打断跑动。待机射击采用拉弦姿态，箭离弦后回待机。
- 这是可用于实际场景评审的精修动作样例：只有两个跨步关键帧，仍需后续扩充过渡、逐向手部对位及真正开弓形变。不可称为正式完整人物动画已经验收。
- 原 SVG 初稿保留作为占位阶段来源，可由 `scripts/generate-mvp-art.cjs` 复现；本轮场景不加载旧人物与弓箭。
